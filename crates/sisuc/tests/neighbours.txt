# The neighbouring forms of the checker's special cases: each spelling of a value that the
# checker treats in its own way, and each position that a join or an expected type gives it.
#
# A fix brief and a review take their "fix the class" list from here: list each value in each
# context, and probe each pair. When a review finds a neighbour that this file does not name, add
# it here, so that the next list has it.
#
# `tests/neighbours.rs` puts each value of `[values]` into the `$` of each line of `[contexts]`.
# It writes the statement into the two `{stmt}` places of `[template]` (`main` and a generic
# function), and runs `sisu check` on each program.
#
# It also puts each value of `[failed values]` into each context. It writes that statement into
# the one `{stmt}` of `[failed]`, a function whose bound failed. That function goes in a second
# program, after the template with no statement. The program always fails, so `check` stops before
# the later passes. Only a value that reads the parameter `u` reaches its unknown state, so each
# value of `[failed values]` holds `u`.
#
# Most programs are wrong. The test fails when `sisu check` crashes on one, as a reached `panic!`
# or `assert!` in the checker does.
#
# A line that starts with `#` is a comment. Each value and each context is one line.

[template]

}

    fn tail(self) -> i64
}

fn generic<U: Named, V>(u: U, v: V, c: bool, d: bool, k: i64, n: any Named, p: any Pet, op: (any Pet)?, ob: Bx?) {
    let mut mq: (any Pet)? = op
    {stmt}
}
fn main() {
    let c = true
    let d = false
    let k = 1
    let n: any Named = Cat()
    let p: any Pet = Fox()
    let op: (any Pet)? = Fox()
    let ob: Bx? = Bx()
    generic(Cat(), Rock(), c, d, k, n, p, op, ob)
    let mut mq: (any Pet)? = op
    {stmt}
}
