# The form matrix: each spelling of a value that the checker treats in its own way, in each
# position that a join or an expected type gives it.
#
# A fix brief and a review take their "fix the class" list from here: list each value in each
# context, and probe each pair. When a review finds a form that this file does not name, add
# it here, so that the next list has it.
#
# `tests/form_matrix.rs` puts each value of `[values]` into the `$` of each line of `[contexts]`.
# It writes the statement into the two `{stmt}` places of `[template]` (`main` and a generic
# function), and runs `sisu check` on each program.
#
# It also puts each value of `[failed values]` into each context. It writes that statement into
# the one `{stmt}` of `[failed]`, a function whose bound failed. That function goes in a second
# program, after the template with no statement. The program always fails, so `check` stops before
# the later passes. Only a value that reads the parameter `u` reaches its unknown state, so each
# value of `[failed values]` holds `u`.
#
# Most programs are wrong. The test fails when `sisu check` crashes on one, as a reached `panic!`
# or `assert!` in the checker does. It also fails when a safe fix of one breaks its contract: applied
# alone, it removes a diagnostic that does not carry it, or adds a syntax error.
#
# A line that starts with `#` is a comment. Each value and each context is one line.
#
# The path of the file is one more form: the renderer repairs the header of a cut line, and
# the path can hold text that looks like a header. No value or context writes the path, so the unit
# test `a_header_whose_path_holds_a_line_break_should_give_the_true_column` in
# `crates/sisuc/src/diagnostic/render.rs` holds its three forms: a path that holds a line break
# (`long\nname.sisu`), one that holds `-->` (`a --> b.sisu`, `a\n--> b.sisu`) and one that holds
# `:::` (`a ::: b.sisu`). The tests `source_text_like_a_later_header_should_not_change` and
# `source_text_like_an_earlier_header_should_not_change` in the same file hold the same text in
# the source.
