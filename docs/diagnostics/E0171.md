# E0171: one place passed `mut` twice

Two `mut` arguments of one call cannot name the same place, and one cannot be inside the other.

## Why

Each `mut` argument stores a value back into its place. When two arguments name one place, the last store-back wins, and the first change is lost. The compiler reports it when it can see it: the same local, the same fields, and indexes that are the same literal or the same `let` local.

A class object is shared, so a field of an object is not inside the local that holds the object: `f(mut p, mut p.x)` is allowed for a class `p`. An element of an array is inside the array.

## Broken

```sisu
fn swap(mut a: i64, mut b: i64) {
    let t = a
    a = b
    b = t
}

fn main() {
    let mut x = 1
    swap(mut x, mut x)
    print(x)
}
```

## Fixed

```sisu
fn swap(mut a: i64, mut b: i64) {
    let t = a
    a = b
    b = t
}

fn main() {
    let mut x = 1
    let mut y = 2
    swap(mut x, mut y)
    print(x)
    print(y)
}
```
