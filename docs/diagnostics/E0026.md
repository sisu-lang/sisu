# E0026: name taken by a built-in

The names `i64`, `u8`, `f64`, `bool`, `char` and `string` belong to the built-in types. A class, a function, an enum or a constant cannot take one. A variant cannot be called `None`, which is a keyword.

The names `Option`, `Result`, `Some`, `Ok` and `Err` are built in too: no class, function, enum, constant, variant, local or parameter can take one. A field or a method can, since it is always reached through a value.

The names `Display`, `Eq`, `Ord` and `AnyObject` belong to the interfaces of the language: no class, function, enum, constant, interface or type parameter can take one. A local, a parameter, a field, a method or a variant can.

## Why

A type name stands where a type is expected, and `u8(...)`, `i64(...)`, `f64(...)` and `char(...)` convert a value. A class, a function or a constant with one of these names would make the same word mean two things. `Option` and `Result` name types, and `Some(x)`, `Ok(x)` and `Err(e)` build their values, so they are kept for them.

## Broken

```sisu
class u8 {
    n: i64
}

fn main() {
    print(1)
}
```

## Fixed

```sisu
class Byte {
    n: i64
}

fn main() {
    let b = Byte(n: 1)
    print(b.n)
}
```
