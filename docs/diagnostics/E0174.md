# E0174: `let` pattern with no `else`

A `let` with a pattern that is not a single name or `_` needs an `else` block, because the pattern can fail to match. A pattern that cannot fail does not belong in a `let`.

## Why

`let x = 1` always works: a name matches every value. `let Some(v) = o` does not: when `o` is `None`, there is no `v`. The compiler cannot give `v` a value, so the `let` must say what to do instead. Add an `else` block that does not finish, and the names that the pattern binds are in scope after the `let`. Or use `if let` or `match`, which run code only when the pattern matches.

A pattern that always matches, such as the only variant of an enum, gets this error too, with the help "use `match`". A `let` takes a variant apart only with an `else` ([ADR 0044](../adr/0044-let-else-and-jumps-are-expressions.md)), and then only when the pattern can fail. A value that is not an enum or an optional gives [E0051](E0051.md). A name that is no variant of the enum gives [E0118](E0118.md).

There is no fix: only the author of the program knows what the `else` block must do.

## Broken

```sisu
fn main() {
    let o: i64? = None
    let Some(v) = o
    print(v)
}
```

## Fixed

```sisu
fn main() {
    let o: i64? = None
    let Some(v) = o else { return }
    print(v)
}
```
