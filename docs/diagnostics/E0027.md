# E0027: class that can never be constructed

A class cannot have a field that needs an object of the class itself, directly or through other classes, unless some field on the way is optional. No first object of such a class could exist.

An enum has the same error when every one of its variants needs a value of the enum itself, directly or through other classes and enums: "no value of `Bad` can be built", with the chain of fields that needs a `Bad`. One variant that needs no such value is enough: an enum `List` with the variants `Nil` and `Cons(i64, List)` can be built from `List.Nil`.

A struct has the same error when a field needs a value of the struct itself, directly or through other classes, enums and structs. A field of type `S?` ends the chain. An enum on the way with a variant that holds no `S` also ends it. For example, `struct S { e: E }` with `enum E { A(s: S); B }` can be built from `E.B`.

## Why

To build a `Node`, Sisu needs the `Node` that its field `next` holds, and to build that one it needs another. An optional field, written `Node?`, can hold `None` and ends the chain.

## Broken

```sisu
class Node {
    next: Node
}

fn main() {
    print(1)
}
```

## Fixed

```sisu
class Node {
    next: Node?
}

fn main() {
    let n = Node(next: None)
    print(n.next == None)
}
```
