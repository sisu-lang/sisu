# E0010: character that Sisu does not use

Source text uses only the characters of Sisu's tokens. Any other character outside a comment is an error. A lone `&` or `|` between two operands is most likely a logical `&&` or `||` written with one character.

## Why

The compiler cannot tell what an unknown character was meant to be. For a `&` or `|` between two operands, the report offers `&&` or `||` as an unsafe fix, which you check before you apply it.

The report offers no fix in any other place: a `&` or `|` that starts an operand, a `&` or `|` with no operand after it (also when a `{` that opens a body follows), or a `&` in a binding, a type or a pattern. A `&&` or `||` there would be an error too. The rule holds in a file with a bracket that does not close.

## Broken

```sisu
fn main() {
    let ok = true & false
    print(ok)
}
```

## Fixed

```sisu
fn main() {
    let ok = true && false
    print(ok)
}
```
