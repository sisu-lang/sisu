# E0051: `let`, `if let` or `while let` on a value that is not an enum or optional

`if let` and `while let` test an enum against a pattern, or unwrap an optional: they run their block with the names the pattern binds, when the value matches.

## Why

A value that is not optional is always there, so there is nothing to test. Use the value itself.

A `let` with a pattern gives this error too, with or without an `else`. The value must be an enum or an optional. For example, `let P(a, b) = p` is this error when `p` is a class `P`.

## Broken

```sisu
fn main() {
    let n = 5
    if let x = n {
        print(x)
    }
}
```

## Fixed

```sisu
fn main() {
    let n: i64? = 5
    if let x = n {
        print(x)
    }
}
```
