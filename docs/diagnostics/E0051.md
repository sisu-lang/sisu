# E0051: `if let` or `while let` on a value that is not an enum or optional

`if let` and `while let` test an enum against a pattern, or unwrap an optional: they run their block with the names the pattern binds, when the value matches.

## Why

A value that is not optional is always there, so there is nothing to test. Use the value itself.

A `let` with a pattern and no `else` gives this error too, when the value is not an enum or an optional: `let P(a, b) = p` with a class `P`.

## Broken

```sisu
fn main() {
    let n = 5
    if let x = n {
        print(x)
    }
}
```

## Fixed

```sisu
fn main() {
    let n: i64? = 5
    if let x = n {
        print(x)
    }
}
```
