# E0001: assignment to something that cannot change

Only a variable, declared with `let mut`, a `mut` field, or an element of an
array held in one of them can be assigned. A `let` binding, a parameter, a
binding made by `for`, `if let` or `while let`, a field without `mut` and a
constant keep the value they were given. This holds for `=` and for compound assignments
such as `+=`.

A `push` changes the array that it pushes onto, so it needs the same kind of place. `xs.push(4)`
is this error when `xs` is a `let` binding or a parameter, or a field without `mut`. So is
`xs?.push(4)` on an optional array. The fixes are the ones for an assignment.

## Why

Sisu marks everything that can change with `mut`
([ADR 0011](../adr/0011-let-mut-marks-what-can-change.md)), so a reader knows
that a binding or field without it keeps its value. A parameter keeps the value
it was passed, so assigning to one never changes the caller's value.

## Broken

```sisu
fn main() {
    let total = 0
    total = 5
    print(total)
}
```

## Fixed

```sisu
fn main() {
    let mut total = 0
    total = 5
    print(total)
}
```
