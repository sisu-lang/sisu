# E0093: literal that is not closed

A `char` literal ends with a `'` on the line it starts on, and a string literal with a `"` on the line it starts on, interpolations included. A line break or the end of the file before that quote is an error, reported at the opening quote. Write `\n` for a line break in a string. A `{` starts an interpolation, so in `"x{"` the second `"` opens a new literal inside it; write `\{` for a literal brace.

## Why

The compiler cannot tell where the literal should have ended, so it offers no fix.

## Broken

```sisu
fn main() {
    let c = 'a
    print(c)
}
```

## Fixed

```sisu
fn main() {
    let c = 'a'
    print(c)
}
```
