# E0170: `mut` argument with the wrong type

A `mut` argument must have exactly the type of its parameter. No conversion applies to it.

## Why

The callee stores its final value back into the place. When the parameter is `i64?`, the callee can store `None`, and an `i64` place cannot hold it. So a value is not promoted to an optional, as an ordinary argument is.

A place that goes through `?.` has two types: it reads as an optional, and it is written as the type that its field stores. A `mut` parameter needs one type for both, so no parameter type fits. Unwrap the object with `if let`, and pass the field of the unwrapped object.

## Broken

```sisu
fn clear(mut n: i64?) {
    n = None
}

fn main() {
    let mut n = 1
    clear(mut n)
    print(n)
}
```

## Fixed

```sisu
fn clear(mut n: i64?) {
    n = None
}

fn main() {
    let mut n: i64? = 1
    clear(mut n)
    print(n ?? 0)
}
```
