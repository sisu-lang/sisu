# E0065: constructor argument without a label

Each argument of a constructor is labeled with the field it sets: `Point(x: 1)`. A variant whose payload is labeled is built the same way: `Shape.Rect(w: 2, h: 3)`. A variant with an unlabeled payload, such as `Num(i64)`, takes its arguments without labels; a label there is [E0055](E0055.md).

## Why

The label says which field gets which value. So a constructor reads the same however many fields its class, struct or variant has. A swap of two values of one type cannot go unnoticed.

## Broken

```sisu
class Point {
    x: i64
}

fn main() {
    let p = Point(1)
    print(p.x)
}
```

## Fixed

```sisu
class Point {
    x: i64
}

fn main() {
    let p = Point(x: 1)
    print(p.x)
}
```
