# E0138: type that cannot be a type argument

A type argument is a type a value can have: not `unit` and not `never`. An optional, such as `i64?`, can be a type argument.

## Why

A type parameter stands for the type of values: of a field, a payload, a parameter or an element. `unit` and `never` are the types of no value, so they stand for nothing there.

## Broken

```sisu
class Cell<T> {
    value: T
}

fn main() {
    let c: Cell<unit>? = None
    print(c == None)
}
```

## Fixed

```sisu
class Cell<T> {
    value: T
}

fn main() {
    let c: Cell<bool>? = Cell(value: true)
    print(c?.value ?? false)
}
```
