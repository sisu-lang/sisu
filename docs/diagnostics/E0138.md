# E0138: type that cannot be a type argument

A type argument is a type a value can have: not `never`. An optional, such as `i64?`, can be a type argument, and so can `unit`.

For a string literal, the error underlines the first part of the literal that never finishes.

## Why

A type parameter stands for the type of values: of a field, a payload, a parameter or an element. `never` is the type of no value, so it stands for nothing there.

## Broken

```sisu
fn id<T>(x: T) -> T {
    x
}

fn main() {
    let a = id(panic("x"))
}
```

## Fixed

```sisu
fn id<T>(x: T) -> T {
    x
}

fn main() {
    let a = id(1)
    print(a)
}
```
