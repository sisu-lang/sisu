# E0138: type that cannot be a type argument

A type argument is a type a value can have, and not an optional: not `unit`, not `never`, and, for now, not `i64?`.

## Why

A type parameter stands for the type of values: of a field, a payload, a parameter or an element. `unit` and `never` are the types of no value, so they stand for nothing there.

A type parameter `T` may itself be made optional, as `T?`. With `i64?` for `T`, that would be an optional of an optional, which Sisu does not have ([E0014](E0014.md)). Until type parameters can say that they are never optional, an optional cannot be a type argument. An array of optionals, `[i64?]`, can.

## Broken

```sisu
class Cell<T> {
    value: T
}

fn main() {
    let c: Cell<unit>? = None
    print(c == None)
}
```

## Fixed

```sisu
class Cell<T> {
    value: T
}

fn main() {
    let c: Cell<bool>? = None
    print(c == None)
}
```
