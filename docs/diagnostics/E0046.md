# E0046: `is` on something that is not an object

`is` tests identity, so both sides must be objects: values of a class, or optionals of one. A number, a `bool`, a `string`, an array or an enum value is not.

## Why

A number, a `string`, an array or an enum value is a value. Two of them are the same when they are equal, and `==` tests that. Identity only makes a difference between objects.

A value whose type is a type parameter `T` may not be an object, so `is` does not take it either. Add the bound `T: AnyObject` to make it one: only a class has `AnyObject`, so `T` is then always an object. `==` needs a bound too ([E0139](E0139.md)).

An optional of an optional, such as a `Node??`, is not an object either: its outer layer can hold a `None` of the inner one. Peel one layer with `??` first: `(a ?? None) is b`.

## Broken

```sisu
fn main() {
    let a = 1
    let b = 1
    print(a is b)
}
```

## Fixed

```sisu
fn main() {
    let a = 1
    let b = 1
    print(a == b)
}
```
