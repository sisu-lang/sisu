# E0052: call of a function that does not exist

A call must name a function of the program, a class, a prelude function (`print`, `eprint`, `panic`, `read_line`), or a conversion `i64(...)`, `u8(...)`, `f64(...)`, `char(...)` or `string(...)`.

When a function, class, prelude function or conversion has a similar name, or another language's name for one, such as `readln` or `input`, the error offers it as an unsafe fix. The unsafe fix may be wrong: the name could be a function that was never written.

A name that is no function also gives this error when the program calls it: a binding, a constant, a type parameter or an associated type. The message says what the name is, as in "`K` is a constant, not a function". It offers no fix.

## Why

Sisu does not resolve a misspelled function name on its own. A misspelled name, or a function that was never written, would otherwise run some other code or none.

## Broken

```sisu
fn total(a: i64, b: i64) -> i64 {
    a + b
}

fn main() {
    print(sum(1, 2))
}
```

## Fixed

```sisu
fn total(a: i64, b: i64) -> i64 {
    a + b
}

fn main() {
    print(total(1, 2))
}
```
