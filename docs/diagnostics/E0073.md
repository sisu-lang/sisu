# E0073: assignment to `self`

A method cannot assign a new object to `self`.

## Why

An object is shared: every variable that holds it refers to the same object. Assigning to `self` would only change what the method calls `self`, not the object the caller has. To change the object, assign to its `mut` fields.

In a method of a struct or an enum, `self` can change when the method takes `mut self`. With plain `self`, an assignment to `self` is this error. The fix is to take `mut self`. It is an unsafe fix, because the method then changes the place of its caller. An interface can require the method with plain `self`. Then the method keeps it, and the help tells you to copy `self` into a `let mut` variable. The class text, about shared objects, is for a class only.

## Broken

```sisu
class Point {
    mut x: i64

    fn reset(self) {
        self = Point(x: 0)
    }
}

fn main() {
    let p = Point(x: 1)
    p.reset()
    print(p.x)
}
```

## Fixed

```sisu
class Point {
    mut x: i64

    fn reset(self) {
        self.x = 0
    }
}

fn main() {
    let p = Point(x: 1)
    p.reset()
    print(p.x)
}
```
