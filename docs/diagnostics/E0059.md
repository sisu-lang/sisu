# E0059: `print` or `eprint` of something it cannot print

`print` and `eprint` take exactly one value that is not an optional, and write it on its own line: `print` to standard output, `eprint` to standard error. The message names the function that was called.

## Why

A call that returns nothing has no value to print. A call with no argument, or with several, is not a call with one value. An optional can be `None`, so a program unwraps it first.

## Broken

```sisu
fn greet() {
    print(1)
}

fn main() {
    print(greet())
}
```

## Fixed

```sisu
fn greet() -> string {
    "hello"
}

fn main() {
    print(greet())
}
```
