# E0059: `print` or `eprint` of something it cannot print

`print` and `eprint` take exactly one value, and write it on its own line: `print` to standard output, `eprint` to standard error. The message names the function that was called, and it says which rule the call breaks.

## Why

A call that returns nothing has no value to print: the message says that its argument has no value. A call with no argument, or with several, is not a call with one value: the message says that the function takes one value.

## Broken

```sisu
fn greet() {
    print(1)
}

fn main() {
    print(greet())
}
```

## Fixed

```sisu
fn greet() -> string {
    "hello"
}

fn main() {
    print(greet())
}
```
