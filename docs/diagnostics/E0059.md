# E0059: `print`, `eprint` or `dbg` with a wrong number of values

`print` and `eprint` take exactly one value, and write it on its own line: `print` to standard output, `eprint` to standard error. `dbg` takes exactly one value too: it writes the value to standard error with its position and source text, and returns it. The message names the function that was called, and it says that the function takes one value.

## Why

A call with no argument, or with several, is not a call with one value. The rules for `dbg` are the rules for `print`: `dbg()` and `dbg(1, 2)` are both this error.

An argument that has no value is not this error. An `if` without an `else` whose branch has a value has no value, and it gives [E0043](E0043.md).

## Broken

```sisu
fn main() {
    print(1, 2)
}
```

## Fixed

```sisu
fn main() {
    print(1)
    print(2)
}
```
