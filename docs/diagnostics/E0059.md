# E0059: `print`, `eprint` or `dbg` of something it cannot print

`print` and `eprint` take exactly one value, and write it on its own line: `print` to standard output, `eprint` to standard error. `dbg` takes exactly one value too: it writes the value to standard error with its position and source text, and returns it. The message names the function that was called, and it says which rule the call breaks.

## Why

A call that returns nothing has no value to print: the message says that its argument has no value. A call with no argument, or with several, is not a call with one value: the message says that the function takes one value. The rules for `dbg` are the rules for `print`: `dbg(greet())` of a call that returns nothing, `dbg()` and `dbg(1, 2)` are all this error.

## Broken

```sisu
fn greet() {
    print(1)
}

fn main() {
    print(greet())
}
```

## Fixed

```sisu
fn greet() -> string {
    "hello"
}

fn main() {
    print(greet())
}
```
