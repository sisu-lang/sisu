# E0020: `self` that is not the first parameter

`self` is only the first parameter of a method. It cannot follow another parameter, repeat, or appear in a function outside a class.

## Why

A method call `object.method(x)` passes the object first, so `self` must come first in the declaration too.

## Broken

```sisu
class Counter {
    mut n: i64

    fn add(by: i64, self) {
        self.n += by
    }
}

fn main() {
    let c = Counter(n: 0)
    c.add(2)
    print(c.n)
}
```

## Fixed

```sisu
class Counter {
    mut n: i64

    fn add(self, by: i64) {
        self.n += by
    }
}

fn main() {
    let c = Counter(n: 0)
    c.add(2)
    print(c.n)
}
```
