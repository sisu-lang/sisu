# E0161: type alias that refers to itself

A type alias is another name for a type. An alias cannot refer to itself, directly or through other aliases.

## Why

The compiler replaces an alias with the type that it names. An alias that refers to itself never stops: `Tree` in `type Tree = [Tree]` would be `[[[...]]]`, a type with no end. The same holds for aliases that refer to each other, such as `type A = B` and `type B = [A]`.

A class or an enum can hold itself. It is a type with a name, and its field holds a value of that name, not a copy of the type. Use a class or an enum for a type that holds itself.

## Broken

```sisu
type Tree = [Tree]

fn main() {
    print(1)
}
```

## Fixed

```sisu
class Tree {
    children: [Tree]
}

fn main() {
    let tree = Tree(children: [])
    print(tree.children.len())
}
```
