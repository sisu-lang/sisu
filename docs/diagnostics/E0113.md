# E0113: variant name not capitalized

A variant name starts with an upper-case letter: `North`, not `north`. The unsafe fix capitalizes it. A name that does not start with a lower-case letter, such as `_north`, gets no fix: capitalizing `_north` would change nothing.

## Why

A pattern tells a variant from a new binding by its first letter: `North => ...` tests for the variant, and `north => ...` binds whatever value is there. The fix is unsafe because the capitalized name may already be taken.

## Broken

```sisu
enum Direction {
    north
    South
}

fn main() {
    print(1)
}
```

## Fixed

```sisu
enum Direction {
    North
    South
}

fn main() {
    let d = Direction.North
    print(d == Direction.South)
}
```
