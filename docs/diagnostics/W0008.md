# W0008: loop label that is never used

A loop label that no `break` or `continue` names is a warning, and the program still builds. The fix deletes the loop label, and its line break when it stands on a line of its own. A loop label that only a failed jump names is not reported: that jump's error is.

## Why

A loop label tells a reader that a jump inside the loop names it. One that no jump names is left over from an edit, or belongs to a `break` or `continue` that lost its loop label. Deleting it changes nothing the program does.

## Broken

```sisu
fn main() {
    outer: for x in [1, 2] {
        print(x)
    }
}
```

## Fixed

```sisu
fn main() {
    for x in [1, 2] {
        print(x)
    }
}
```
