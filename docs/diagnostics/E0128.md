# E0128: wrong number of sub-patterns

A variant pattern lists one sub-pattern for each field of the variant: `Add(a, b)` for a variant with two fields.

## Why

Sub-patterns match fields by position, so a missing or extra one leaves it unclear which field each name binds. Use `_` for a field you do not need.

## Broken

```sisu
enum Expr {
    Num(i64)
    Add(i64, i64)
}

fn eval(e: Expr) -> i64 {
    match e {
        Num(n) => n
        Add(a) => a
    }
}

fn main() {
    print(eval(Expr.Num(1)))
    print(eval(Expr.Add(2, 3)))
}
```

## Fixed

```sisu
enum Expr {
    Num(i64)
    Add(i64, i64)
}

fn eval(e: Expr) -> i64 {
    match e {
        Num(n) => n
        Add(a, _) => a
    }
}

fn main() {
    print(eval(Expr.Num(1)))
    print(eval(Expr.Add(2, 3)))
}
```
