# E0162: type that holds too many distinct types

The type that a written type names, once its type aliases are replaced, holds more than 100,000 distinct types.

## Why

A type alias with a parameter can use another alias twice, each time with a different argument. A chain of such aliases doubles the number of types at each step, so a chain of 30 aliases names 2^30 types, though no alias is deep. The compiler builds each distinct type once. It stops at 100,000 types for one written type, and reports the type that goes past the limit. Every alias that uses it is then an error, without a report of its own.

A second limit covers the whole program: the aliases may build 1,000,000 distinct types in all, whatever the written types add. A program with many uses of one alias, each with a type of its own, passes it without any one type passing the first limit. The compiler then reports the type that goes past it, with a message that names the limit of the program, and every later use of an alias is an error without a report of its own. The help is the same.

Hold an inner part of the type in a field of a class or an enum. A class and an enum have a name, so the types inside it are not part of the type that names it.

## Broken

```sisu
class Pair<A, B> {
    first: A
    second: B
}

type B1<T> = Pair<[T], T?>
type B2<T> = Pair<B1<[T]>, B1<T?>>
type B3<T> = Pair<B2<[T]>, B2<T?>>
type B4<T> = Pair<B3<[T]>, B3<T?>>
type B5<T> = Pair<B4<[T]>, B4<T?>>
type B6<T> = Pair<B5<[T]>, B5<T?>>
type B7<T> = Pair<B6<[T]>, B6<T?>>
type B8<T> = Pair<B7<[T]>, B7<T?>>
type B9<T> = Pair<B8<[T]>, B8<T?>>
type B10<T> = Pair<B9<[T]>, B9<T?>>
type B11<T> = Pair<B10<[T]>, B10<T?>>
type B12<T> = Pair<B11<[T]>, B11<T?>>
type B13<T> = Pair<B12<[T]>, B12<T?>>
type B14<T> = Pair<B13<[T]>, B13<T?>>
type B15<T> = Pair<B14<[T]>, B14<T?>>
type B16<T> = Pair<B15<[T]>, B15<T?>>

fn main() {
    print(1)
}
```

## Fixed

```sisu
class Pair<A, B> {
    first: A
    second: B
}

class Level<T> {
    inner: Pair<[T], T?>
}

type B1<T> = Pair<[T], T?>
type B2<T> = Pair<Level<[T]>, Level<T?>>

fn main() {
    let level: Level<i64> = Level(inner: Pair(first: [1], second: Some(2)))
    let inner: B1<i64> = level.inner
    print(inner.first.len())
    print(inner.second ?? 0)
}
```
