# E0106: math written another way

Other languages write math as `Math.sqrt(x)`, `math.pi` or `Math.PI`, and Sisu does not. Math in Sisu is methods and constants on `f64`: `x.sqrt()` and `f64.pi`. The error points at the `math.` or `Math.` form that a method or constant of `f64` replaces. It also covers `f64.max(a, b)`, which is the method call `a.max(b)`.

The fix is safe, because it checks. A constant is always safe: `math.pi`, `Math.PI` and `math.inf` become `f64.pi` and `f64.infinity`, whatever the case. A method call is safe when its first argument has the method, and the other arguments are the method's parameters. Otherwise there is no fix: `math.sqrt(n)` with `n: i64` has no method to call, and `math.sqrt(x, 2.0)` has an argument too many. The fix keeps the comments in the call, as for [E0070](E0070.md). A constant whose name follows a comment, as `math // c` and then `.PI`, gets an unsafe fix that removes the comment.

## Why

A method belongs to the value it works on. `x.sqrt()` reads left to right, and the value says which `sqrt` it is. There is no `math` module in Sisu, so `math` and `Math` are ordinary names. A local called `math` is a value, and its members are its own. With no such name, `math.foo` is [E0033](E0033.md).

## Broken

```sisu
fn main() {
    let x = 2.0
    print(math.sqrt(x))
}
```

## Fixed

```sisu
fn main() {
    let x = 2.0
    print(x.sqrt())
}
```
