# E0061: `print`, `eprint` or `dbg` of an expression that never finishes

The argument of `print`, `eprint` or `dbg` must finish with a value. An expression such as an `if` whose branches all `return`, or a `panic`, never does, so the call never runs.

## Why

A `print`, `eprint` or `dbg` that can never write is a mistake: the program meant to write a value, or meant the `return` or `panic` without the call. `dbg(panic("x"))` is this error as `print(panic("x"))` is.

## Broken

```sisu
fn report(ok: bool) {
    print(if ok { return } else { return })
}

fn main() {
    report(true)
}
```

## Fixed

```sisu
fn report(ok: bool) {
    print(if ok { 1 } else { 0 })
}

fn main() {
    report(true)
}
```
