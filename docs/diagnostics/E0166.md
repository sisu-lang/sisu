# E0166: `mut` parameter without `mut` on its argument

An argument for a `mut` parameter needs `mut` in front of it.

## Why

A `mut` parameter lets the callee change the place that the argument names. The callee copies the value in, and at the end it stores the value back. The `mut` before the argument shows this at the call, so a reader sees which places a call can change.

When the argument is a place that fits the parameter, the fix adds `mut`. A `let` local or a field that is not `mut` cannot change: the help says how to declare it. An argument that is not a place, such as a literal or a call, cannot change at all. To change only a local copy, remove `mut` from the parameter and write `let mut n = n` in the body.

## Broken

```sisu
fn set(mut xs: [i64]) {
    xs[0] = 9
}

fn main() {
    let mut xs = [1, 2]
    set(xs)
    print(xs)
}
```

## Fixed

```sisu
fn set(mut xs: [i64]) {
    xs[0] = 9
}

fn main() {
    let mut xs = [1, 2]
    set(mut xs)
    print(xs)
}
```
