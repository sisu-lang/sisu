# E0146: body or field in an interface

An interface holds method signatures and associated types, and nothing else. A method in an interface has no body, and an interface has no fields.

## Why

An interface says what a type can do, not how it does it. Each type that conforms to the interface writes its own body for each method, so a body in the interface would have no meaning. A field belongs to a class: an interface cannot say how a type stores its data. Write the body in each conforming type, and the field in the class.

## Broken

```sisu
interface Shape {
    fn area(self) -> f64 {
        0.0
    }
}

fn main() {
    print(1)
}
```

## Fixed

```sisu
interface Shape {
    fn area(self) -> f64
}

fn _area<T: Shape>(_shape: T) {
    print(1)
}

fn main() {
    print(1)
}
```
