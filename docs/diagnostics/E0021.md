# E0021: assignment to something that is not a place

The left side of `=` or of a compound assignment such as `+=` must be a variable, a field, or an element of an array.

## Why

An assignment stores a value in a place. A sum or a call result is a value without a place, so nothing can hold what you assign to it.

A `push` is the same. `numbers().push(4)` adds an element to the array that `numbers()` returns,
and nothing keeps that array, so the element would be lost. Store the array in a `let mut`
variable first, and push onto the variable.

## Broken

```sisu
fn main() {
    let mut x = 1
    x + 1 = 3
    print(x)
}
```

## Fixed

```sisu
fn main() {
    let mut x = 1
    x = 3
    print(x)
}
```
