# E0021: assignment to something that is not a place

The left side of `=` or of a compound assignment such as `+=` must be a variable, a field, or an element of an array.

## Why

An assignment stores a value in a place. A sum or a call result is a value without a place, so nothing can hold what you assign to it.

A `push` is the same. `numbers().push(4)` adds an element to the array that `numbers()` returns,
and nothing keeps that array, so the element would be lost. Store the array in a `let mut`
variable first, and push onto the variable.

A range index is a value too. `xs[1..3]` is a new array and `s[0..2]` is a new string, so an assignment to one would be lost. The help repeats your own code:

- An assignment to a range of an array, `xs[0..2] = ys`: assign to each element, `xs[i] = ...`, in a loop.
- An element of a range, `xs[1..][0] += 5`: write `xs[1 + 0] += 5`. A range index counts from its start.
- An assignment to a range of a string, `s[0..2] = t`: build the new string, such as `s = s[..0] + t + s[2..]`.
- A `+=` to a range of a string, `s[0..2] += t`: this appends `t` to the selected text, so build the new string, such as `s = s[..2] + t + s[2..]`. With no end, `s[1..] += t`, write `s += t`.

## Broken

```sisu
fn main() {
    let mut x = 1
    x + 1 = 3
    print(x)
}
```

## Fixed

```sisu
fn main() {
    let mut x = 1
    x = 3
    print(x)
}
```
