# E0022: assignment through `?.`

An assignment cannot go through `?.`, because the object may be `None` and then there is nothing to assign to.

## Why

`?.` stands for "if there is an object". Unwrap the optional with `if let`, so the assignment sits in the branch where the object exists.

## Broken

```sisu
class Node {
    mut value: i64
}

fn main() {
    let node: Node? = Node(value: 1)
    node?.value = 2
}
```

## Fixed

```sisu
class Node {
    mut value: i64
}

fn main() {
    let node: Node? = Node(value: 1)
    if let n = node {
        n.value = 2
        print(n.value)
    }
}
```
