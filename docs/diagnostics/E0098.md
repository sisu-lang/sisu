# E0098: value that cannot be interpolated

An interpolation writes the text of a value as `print` does, for any type that has a `Display`: a number, a `bool`, a `char`, a `string`, an array, an object, an enum or a value of a type parameter. A `unit` value has no text, and an optional may be `None`, so interpolating either is an error at the interpolated expression.

## Why

A call that returns nothing has no value to write. An optional may be `None`, which the program must decide how to show: unwrap it with `if let`, or give a default through `??`. To write `None` on purpose, call `to_string()` on the optional.

## Broken

```sisu
fn main() {
    let name: string? = "Sisu"
    print("Hello {name}")
}
```

## Fixed

```sisu
fn main() {
    let name: string? = "Sisu"
    print("Hello {name ?? "friend"}")
}
```
