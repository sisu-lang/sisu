# E0098: value that cannot be interpolated

Status: retired in [ADR 0051](../adr/0051-a-failure-is-written-t-or-e.md), in milestone 12. A `unit` value has the text `()` now, so an interpolation of one is not an error. An interpolated expression that has no value gives [E0043](E0043.md).

An interpolation writes the text of a value as `print` does, for any type that has a `Display`: a number, a `bool`, a `char`, a `string`, an array, an object, an enum, a `unit` or a value of a type parameter. An optional is not an error: it gets the warning [W0015](W0015.md).

## Why

Before milestone 12, a `unit` value had no text. Interpolating a call that returned nothing was an error at the interpolated expression.

## Broken

```sisu
fn greet() {
    print("hi")
}

fn main() {
    print("Hello {greet()}")
}
```

## Fixed

```sisu
fn greet() -> string {
    "Sisu"
}

fn main() {
    print("Hello {greet()}")
}
```
