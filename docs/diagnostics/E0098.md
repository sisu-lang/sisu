# E0098: value that cannot be interpolated

An interpolation writes the text of a value as `print` does, for any type that has a `Display`: a number, a `bool`, a `char`, a `string`, an array, an object, an enum or a value of a type parameter. A `unit` value has no text, so interpolating one is an error at the interpolated expression. An optional is not an error: it gets the warning [W0015](W0015.md).

## Why

A call that returns nothing has no value to write. Give the text another way, or leave the call out of the interpolation.

## Broken

```sisu
fn greet() {
    print("hi")
}

fn main() {
    print("Hello {greet()}")
}
```

## Fixed

```sisu
fn greet() -> string {
    "Sisu"
}

fn main() {
    print("Hello {greet()}")
}
```
