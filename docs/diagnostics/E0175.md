# E0175: `mut` on a field of a struct

A field of a struct has `mut` in front of it. A field of a class can have `mut`, but a field of a struct cannot.

## Why

A struct is a value. A variable or a field holds the whole struct, and each copy is a different value. So the holder of a struct decides whether its fields can change, not the struct. A `let mut` variable can change each field of the struct that it holds. A `let` variable can change none.

A class is different. A class is a counted object on the heap, and each holder shares the same object. So the class itself says which fields can change, with `mut`.

The safe fix removes the `mut`. The field is then a plain field, and a `let mut` holder can change it.

## Broken

```sisu
struct P { mut x: i64 }

fn main() {
    print(P(x: 1).x)
}
```

## Fixed

```sisu
struct P { x: i64 }

fn main() {
    print(P(x: 1).x)
}
```
