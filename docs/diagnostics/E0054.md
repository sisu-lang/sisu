# E0054: conversion to the type the value already has

`i64(x)` converts a `u8` or a `char` to an `i64`, `f64(x)` converts an `i64` to an `f64`, and `u8(x)` and `char(x)` convert an `i64` to a `u8?` or a `char?`, which is `None` when the value does not fit. `string(x)` builds a `string` from a `[char]`. Its argument must have one of the other types.

The fix removes the conversion, and keeps the parentheses around an argument that is more than one term: `i64(n + 1) * 2` becomes `(n + 1) * 2`. A comment in the conversion stays, and the fix then keeps the parentheses too: `i64(// c` on one line and `n)` on the next becomes `(// c` and `n)`. A conversion whose argument has a label has no fix: the label is [E0055](E0055.md) on its own.

## Why

A conversion of a value that already has the type does nothing. It usually means the value's type is not what the program assumes.

## Broken

```sisu
fn main() {
    let n: i64 = 5
    print(i64(n))
}
```

## Fixed

```sisu
fn main() {
    let n: i64 = 5
    print(n)
}
```
