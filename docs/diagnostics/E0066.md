# E0066: constructor that names its fields out of order

A constructor names the fields of its class, or the labeled payload of its variant, in the order they are declared.

## Why

One order for every constructor of a class or variant makes the constructors easy to compare, and makes the order in which the arguments run the order of the fields.

## Broken

```sisu
class Point {
    x: i64
    y: i64
}

fn main() {
    let p = Point(y: 2, x: 1)
    print(p.x + p.y)
}
```

## Fixed

```sisu
class Point {
    x: i64
    y: i64
}

fn main() {
    let p = Point(x: 1, y: 2)
    print(p.x + p.y)
}
```
