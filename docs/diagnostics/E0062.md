# E0062: optional used as if it were present

A field read, a method call, an index or a `for` needs a value, not an optional of one. An optional may be `None`, which has no fields, methods or elements.

## Why

Sisu has no null pointer errors at runtime: the checker makes the program say what happens when the optional is `None`. `?.` reads the member only when the optional holds a value, and gives `None` otherwise. In an assignment or a `push`, `?.` makes the change only when the optional holds a value, and does nothing otherwise. `if let` runs a block with the value only when it is present.

An element target, such as `m?.items[0] = 2`, writes into the array that `m?.items` holds. An `if let` of that array binds a copy, and you cannot write to a copy. The help names the object of the `?.` instead: `if let m = m { m.items[0] = 2 }` writes into the array of `m`.

An optional of an optional, such as a `Node??`, has two layers, and `?.` takes only one off: `n?.value` on a `Node??` reads `value` from a `Node?`, which may be `None` too. Peel the other layer first with `??`: `(n ?? None)?.value`.

## Broken

```sisu
class Node {
    value: i64
    next: Node?
}

fn second(n: Node) -> i64 {
    n.next.value
}

fn main() {
    print(second(Node(value: 1, next: Node(value: 2, next: None))))
}
```

## Fixed

```sisu
class Node {
    value: i64
    next: Node?
}

fn second(n: Node) -> i64 {
    if let next = n.next {
        next.value
    } else {
        0
    }
}

fn main() {
    print(second(Node(value: 1, next: Node(value: 2, next: None))))
}
```
