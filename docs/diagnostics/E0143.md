# E0143: loop label used by an enclosing loop

A loop may not take the loop label of a loop around it. Two loops side by side may share a loop label.

## Why

A `break` or `continue` that names a loop label reaches the innermost loop around it with that label. When an inner loop takes an outer loop's label, no jump inside the inner loop can name the outer one, and a reader cannot tell which loop a jump was meant for. Rename one of the loop labels, or delete the one no jump needs.

## Broken

```sisu
fn main() {
    outer: for x in [1, 2] {
        outer: for y in [3, 4] {
            if x + y == 5 {
                break outer
            }
            print(y)
        }
    }
}
```

## Fixed

```sisu
fn main() {
    outer: for x in [1, 2] {
        for y in [3, 4] {
            if x + y == 5 {
                break outer
            }
            print(y)
        }
    }
}
```
