# E0011: token where something else belongs

The parser expected one thing and found another. The message names both, with the thing found written as it appears in the source, or as `end of line` or `end of file`.

## Why

Sisu's syntax is small, so the expected thing is nearly always one specific token or kind of name. The message reads as a sentence, such as "expected a binding name, found `=`".

One form has its own message. A `return` or `break` takes everything to its right as its value. When it ends the header of an `if`, a `while`, a `for` or a `match` and a `{` follows, it takes the `{ ... }` of the body as its value, and the body is missing. The report points at the jump. Put the jump in `( )` to give it no value: write `if (o ?? return) {` in place of `if o ?? return {`. In the header of a loop, a `break` cannot be put in `( )` this way, because a `break` in a loop header is E0082 (see [E0082](E0082.md)).

## Broken

```sisu
fn main() {
    let = 1
    print(1)
}
```

## Fixed

```sisu
fn main() {
    let x = 1
    print(x)
}
```
