# E0148: bound that is not an interface

A bound after a type parameter, and an interface in the inheritance list of another interface, names an interface. A class, an enum, a built-in type or a type parameter is not one.

## Why

A bound says what a type must be able to do, and only an interface says that. `T: Circle` would ask `T` to be a class, which a bound cannot do. To accept one class, write its name as the type: `circle: Circle`. To accept many types, write an interface that they conform to.

## Broken

```sisu
class Circle {
    r: f64
}

fn _area<T: Circle>(_shape: T) {
    print(1)
}

fn main() {
    print(2)
}
```

## Fixed

```sisu
interface Shape {
    fn area(self) -> f64
}

fn _area<T: Shape>(_shape: T) {
    print(1)
}

fn main() {
    print(2)
}
```
