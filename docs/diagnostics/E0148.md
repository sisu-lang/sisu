# E0148: bound that is not an interface

A bound after a type parameter, an interface in the conformance list of a class or an enum (`class C: Circle`), and an interface in the inheritance list of another interface, names an interface. A class, an enum, a built-in type, a type parameter, and an optional or an array of any type (`Shape?`, `[Shape]`) are not one.

## Why

A bound says what a type must be able to do, and only an interface says that. `T: Circle` would ask `T` to be a class, which a bound cannot do. To accept one class, write its name as the type: `circle: Circle`. To accept many types, write an interface that they conform to.

`any` takes the name of an interface too. `any Circle` is this error for a class, `any i64` for a built-in type, and `any T` for a type parameter `T`. A type parameter is a bound, not an interface, and `T` is already one type at each use.

`T: any Shape` is this error too, with its own wording: `any Shape` is an interface value, not an interface. A bound names the interface alone, and the help says so: "name the interface without `any`: `Shape`". A function that takes an interface value writes `any Shape` as the type of the parameter, not as a bound.

## Broken

```sisu
class Circle {
    r: f64
}

fn _area<T: Circle>(_shape: T) {
    print(1)
}

fn main() {
    print(2)
}
```

## Fixed

```sisu
interface Shape {
    fn area(self) -> f64
}

fn _area<T: Shape>(_shape: T) {
    print(1)
}

fn main() {
    print(2)
}
```
