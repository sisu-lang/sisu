# E0150: interface that inherits from itself

An interface lists the interfaces it inherits after a `:`. An interface cannot inherit from itself, directly or through other interfaces.

## Why

An interface that inherits another one requires every conforming type to conform to that one too. A cycle asks a type to conform to an interface before it conforms to the same interface, so no type can meet it. Remove one inheritance from the cycle.

## Broken

```sisu
interface Named: Labeled {
    fn name(self) -> string
}

interface Labeled: Named {
    fn label(self) -> string
}

fn main() {
    print(1)
}
```

## Fixed

```sisu
interface Named {
    fn name(self) -> string
}

interface Labeled: Named {
    fn label(self) -> string
}

fn main() {
    print(1)
}
```
