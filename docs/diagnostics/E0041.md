# E0041: `self` outside a method

`self` names the object or the struct value a method was called on, so it is only available inside a method.

## Why

A function that is not a method has no object to refer to. A field is reached through the object, so such a function takes the object as a parameter, or becomes a method.

## Broken

```sisu
class Counter {
    n: i64
}

fn show() {
    print(self.n)
}

fn main() {
    show()
}
```

## Fixed

```sisu
class Counter {
    n: i64

    fn show(self) {
        print(self.n)
    }
}

fn main() {
    Counter(n: 1).show()
}
```
