# E0144: `break` or `continue` naming no loop label around it

A name after `continue` must be the loop label of a loop around it. A name after `break` in a `for`, `while` or `while let` that names nothing in scope, but is close to the loop label of a loop around it, is reported as that loop label misspelled.

## Why

`continue` takes no value, so a name after it can only be a loop label. After `break`, a name that is no loop label begins the value, which only a `loop` takes; in another loop, a name close to a loop label is far more likely a misspelling of it. The help offers the loop label with the similar name. A jump never leaves its function, so only the loops around it in its own function have loop labels it can name.

## Broken

```sisu
fn main() {
    outer: for x in [1, 2] {
        for y in [3, 4] {
            if x + y == 5 {
                continue outr
            }
            print(y)
        }
    }
}
```

## Fixed

```sisu
fn main() {
    outer: for x in [1, 2] {
        for y in [3, 4] {
            if x + y == 5 {
                continue outer
            }
            print(y)
        }
    }
}
```
