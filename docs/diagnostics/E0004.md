# E0004: `{` on a line of its own

The `{` that opens a function, class, enum, interface, `extend` block or other block must stand on the same line as its header: `fn`, `class`, `enum`, `interface`, `extend`, `if`, `else`, `match`, `while`, `for` or `loop`.

## Why

A line break ends a statement, so a `{` on its own line is a new statement, not the body of the header above. Sisu has one layout, with the `{` at the end of the header line, so a reader never has to decide where a body starts.

## Broken

```sisu
fn main()
{
    print(1)
}
```

## Fixed

```sisu
fn main() {
    print(1)
}
```
