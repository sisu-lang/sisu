# E0023: range outside a `for`, a pattern, an index or a string's `get`

A range such as `0..n` or `0..=n` can only be one of these:

- the source of a `for` loop;
- a pattern in a `match` arm;
- an index, as in `xs[1..3]`;
- the argument of a string's `get`.

## Why

A range is not a value in Sisu. It describes what a `for` loop counts through, which values a pattern matches, or which part of an array or a string an index takes. It cannot be stored, passed or returned.

A range with a missing bound, such as `..5`, `2..` or `..`, is allowed only as an index or as the argument of a string's `get`. A `for` loop needs both bounds, because it counts from the start to the end. Write `0..n`, or use `loop` with a counter. `..` alone is the whole value, so write the value itself.

`xs[..]` and `xs[..=]` are `xs`, so they are errors too. Write `xs`. In the same way `s.get(..)` is `Some(s)`, so it is an error. Write `Some(s)`, or the string itself. Through `?.`, `o?.get(..)` is `o`.

`a..=` has no end, so it is not a range. In an index, as in `xs[1..=]`, write `xs[1..]`. In a string's `get`, as in `s.get(1..=)`, write `s.get(1..)`. In a `for` loop, write both bounds. As a value, write the range where it is used.

## Broken

```sisu
fn main() {
    let r = 0..3
    print(1)
}
```

## Fixed

```sisu
fn main() {
    for i in 0..3 {
        print(i)
    }
}
```
