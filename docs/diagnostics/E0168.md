# E0168: `mut` outside an argument

`mut` goes before an argument of a call, for a `mut` parameter. Anywhere else, it has no meaning.

## Why

A `mut` argument tells the reader that the call can change the place that the argument names: the callee copies the value in, and stores it back at the end. A `let` binds a copy of its value, so nothing is stored back, and `return mut x` has no parameter to store into.

To change a bound value, bind it with `let mut`. The fix removes the `mut` and the spaces after it.

## Broken

```sisu
fn main() {
    let x = 1
    let y = mut x
    print(y)
}
```

## Fixed

```sisu
fn main() {
    let x = 1
    let mut y = x
    y += 1
    print(y)
}
```
