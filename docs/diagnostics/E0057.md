# E0057: method read as a field

A method runs when it is called, with `()` and its arguments: `s.area()`. Without the call, `s.area` reads a field, and the class or the struct has no field of that name. The same holds for the array method `len()`.

## Why

Sisu has no method values: a method name alone is not a value that a program can store or pass. Reading one is almost always a call with its `()` left out.

## Broken

```sisu
class Square {
    side: i64

    fn area(self) -> i64 {
        self.side * self.side
    }
}

fn main() {
    let s = Square(side: 2)
    print(s.area)
}
```

## Fixed

```sisu
class Square {
    side: i64

    fn area(self) -> i64 {
        self.side * self.side
    }
}

fn main() {
    let s = Square(side: 2)
    print(s.area())
}
```
