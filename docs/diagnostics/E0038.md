# E0038: `break` or `continue` outside a loop

`break` and `continue` act on the loop around them: `loop`, `while`, or `for`.

## Why

Outside a loop there is nothing to leave or to repeat. To leave a function, use `return`.

## Broken

```sisu
fn main() {
    break
}
```

## Fixed

```sisu
fn main() {
    loop {
        break
    }
}
```
