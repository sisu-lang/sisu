# E0149: `Self` outside a type or an interface

`Self` names the type that a class, an enum, an interface or an `extend` block is about. It is valid only inside one of them.

## Why

Outside them, `Self` has no type to name. A function that is not a method has no type of its own: write the type, or a type parameter.

## Broken

```sisu
fn first(x: i64) -> Self {
    x
}

fn main() {
    print(1)
}
```

## Fixed

```sisu
fn first(x: i64) -> i64 {
    x
}

fn main() {
    print(first(1))
}
```
