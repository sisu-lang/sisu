# E0136: alternatives bind different names

Each alternative of a `|` pattern binds the same names, with the same types, so the arm can use them whichever alternative matched.

## Why

The arm's body runs after any one of the alternatives matches. A name that only some of them bind would have no value when another one matched. Bind the name in every alternative, or use `_` in all of them.

## Broken

```sisu
enum Shape {
    Square(i64)
    Rect(i64, i64)
}

fn width(s: Shape) -> i64 {
    match s {
        Square(w) | Rect(_, h) => w
    }
}

fn main() {
    print(width(Shape.Square(2)))
    print(width(Shape.Rect(3, 4)))
}
```

## Fixed

```sisu
enum Shape {
    Square(i64)
    Rect(i64, i64)
}

fn width(s: Shape) -> i64 {
    match s {
        Square(w) | Rect(w, _) => w
    }
}

fn main() {
    print(width(Shape.Square(2)))
    print(width(Shape.Rect(3, 4)))
}
```
