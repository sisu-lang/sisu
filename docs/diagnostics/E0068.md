# E0068: index of something that does not take that index

An array takes an index, `xs[i]`, and a range index, `xs[a..b]`. A string takes a range index, `s[a..b]`, but not a single index. A range index on any other value is this error too. It does not check the bounds, so this is the only error you get.

## Why

A number, a `bool` or an object holds no elements, so there is nothing for an index to select. A range index cuts a part from an array or a string, so it needs one of them.

## Broken

```sisu
fn main() {
    let n = 5
    print(n[0])
}
```

## Fixed

```sisu
fn main() {
    let xs = [5]
    print(xs[0])
}
```
