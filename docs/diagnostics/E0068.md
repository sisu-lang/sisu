# E0068: index of a value that is not an array, or a single index of a string

An array takes an index, `xs[i]`, and a range index, `xs[a..b]`. A string takes a range index, `s[a..b]`, but not a single index. A range index on any other value is this error too. It does not check the bounds, so this is the only error you get.

## Why

A string has no single index. `s[i]` is this error. Bytes and characters are different in a string, so there is no one value that `s[i]` could mean. For bytes, write `let bs = s.bytes()` once, then `bs[i]`. For characters, write `let cs = s.chars()` once, then `cs[i]`. To change a character, write `let mut cs = s.chars()`, change `cs[i]`, then write `s = string(cs)`. Both `bytes()` and `chars()` build a new array, so a loop must not call them for each index.

A number, a `bool` or an object holds no elements, so there is nothing for an index to select. A range index cuts a part from an array or a string, so it needs one of them.

## Broken

```sisu
fn main() {
    let n = 5
    print(n[0])
}
```

## Fixed

```sisu
fn main() {
    let xs = [5]
    print(xs[0])
}
```
