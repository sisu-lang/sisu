# E0087: constant that uses itself or a constant below it

A constant can use only the constants declared above it. One that names a constant below it, or names itself, is an error.

## Why

The compiler computes constants from top to bottom, so each value is known before the constants below it use it. This also rules out a constant that depends on itself, whose value would have no start. Functions, classes and structs may still appear in any order. Move the constant that is used above the one that uses it.

## Broken

```sisu
const PERIMETER = SIDE * 4
const SIDE = 10

fn main() {
    print(PERIMETER)
}
```

## Fixed

```sisu
const SIDE = 10
const PERIMETER = SIDE * 4

fn main() {
    print(PERIMETER)
}
```
