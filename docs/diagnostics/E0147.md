# E0147: interface used as a type

An interface is not a type. A parameter, a field, a local or an element has a type, and the name of an interface cannot stand in its place. A type parameter with the interface as its bound can. A type alias cannot name an interface either: `type Shapes = Shape` is the same error, and a parameter of an alias takes no bound.

## Why

An interface says what a type can do. It does not say how a value is stored or how big it is. A function that takes any conforming type takes a type parameter with that interface as its bound: `T: Shape`.

## Broken

```sisu
interface Shape {
    fn area(self) -> f64
}

fn _describe(_shape: Shape) {
    print(1)
}

fn main() {
    print(2)
}
```

## Fixed

```sisu
interface Shape {
    fn area(self) -> f64
}

fn _describe<T: Shape>(_shape: T) {
    print(1)
}

fn main() {
    print(2)
}
```
