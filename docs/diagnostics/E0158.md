# E0158: only classes conform to `AnyObject`

`AnyObject` is a language interface with no methods. A class conforms to it without a declaration, and a class can list it. An enum, a built-in type or any other type that is not a class cannot conform to it. This error is on a conformance to `AnyObject` of such a type. The conformance can be written in the list of the type, or in an `extend` block. It can also come from an interface that inherits `AnyObject`: then a note on the error names that interface.

## Why

`AnyObject` says that a value is an object, with an identity. Two names for one object are the same object, and `a is b` tests that. A number, an enum value or an array has no identity: it is a value, and a copy of it is the same value. A function with the bound `T: AnyObject` can use `is` on a `T`, so every `T` must be an object. An interface that inherits `AnyObject` gives the same rule to the types that conform to it. If an enum could conform, the bound would no longer promise an object.

To fix the error, make the type a class, or remove the conformance. If the program needs the interface only for its methods, write the interface without `AnyObject`.

## Broken

```sisu
enum Light: AnyObject {
    Red
    Green
}

fn main() {
    print(1)
}
```

## Fixed

```sisu
class Light: AnyObject {
    on: bool
}

fn main() {
    print(Light(on: true).on)
}
```
