# E0169: `mut` argument that is not a place

A `mut` argument must be a place: a variable, a `mut` field, or an element of one of these.

## Why

The callee stores its final value back into the place that the argument names. A call result, a literal, a `let` binding, a field that is not `mut`, a plain parameter and a range index (`xs[1..3]` gives a new array, and `s[0..2]` a new string) are not places that can change.

To change a `let` binding, declare it with `let mut`. To change a copy of a parameter or of a binding, copy it into a `let mut` local and pass that. An object is shared, so `self` can already write every `mut` field of a class.

## Broken

```sisu
fn set(mut xs: [i64]) {
    xs[0] = 9
}

fn main() {
    let xs = [1, 2]
    set(mut xs)
    print(xs)
}
```

## Fixed

```sisu
fn set(mut xs: [i64]) {
    xs[0] = 9
}

fn main() {
    let mut xs = [1, 2]
    set(mut xs)
    print(xs)
}
```
