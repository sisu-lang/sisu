# E0125: upper-case name where no enum is expected

A name that starts with an upper-case letter in a pattern names a variant, so it can stand only where the value is an enum. Where the value is an integer, a `bool`, a `char` or a `string`, a pattern name is a binding, and a binding starts with a lower-case letter.

## Why

An upper-case name reads as a variant, perhaps misspelled, not as a new name for the value, so the compiler does not quietly bind it. The fix lower-cases the first letter. It is unsafe, since the new name may clash with another. A name that would become a keyword other than `true` or `false`, such as `If`, gets no fix. Its help says that `if` is a keyword. The help for a reserved word, such as `Import`, says that `import` is reserved. Use a different name for both.

## Broken

```sisu
fn main() {
    let n = match 3 {
        Count => Count + 1
    }
    print(n)
}
```

## Fixed

```sisu
fn main() {
    let n = match 3 {
        count => count + 1
    }
    print(n)
}
```
