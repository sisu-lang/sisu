# E0069: `sum` of an array that is not `[i64]` or `[f64]`

`sum()` adds the elements of an array of `i64` or of `f64`.

## Why

Only `i64` and `f64` elements have a sum of the same type. Sisu does not convert a `u8` or a `bool` to a number by itself.

The prelude writes `sum` in Sisu, in an `extend [i64]` block and an `extend [f64]` block. This error means that no such block covers the array. The same error names any other method that the prelude gives to some array types but not to the type of your array.

## Broken

```sisu
fn main() {
    let flags = [true, false]
    print(flags.sum())
}
```

## Fixed

```sisu
fn main() {
    let flags = [true, false]
    let mut count = 0
    for flag in flags {
        if flag {
            count += 1
        }
    }
    print(count)
}
```
