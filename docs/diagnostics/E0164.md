# E0164: interface that cannot be used after `any`

`any Shape` is a value of any type that conforms to `Shape`. Not every interface can be used this way. A call through `any` finds the method in a table that belongs to the value, and it cannot find a method that needs the type of the value itself.

## Why

An `any` value hides its type. These requirements need that type, so an interface that has one cannot be `any`:

- A requirement that takes another `Self`. `Eq` is one: `eq(self, other: Self)` compares two values of the same type, and two `any Eq` values may hold different types. `Ord` is another.
- A requirement that returns `Self`, or a type with `Self` in it, such as `[Self]`. The caller would get a value of a type that it cannot name. The message names the type that the requirement returns.
- A requirement with type parameters of its own. A table has one entry for each requirement, and a generic requirement would need one entry for each type argument.
- An associated type. The type depends on the type of the value, which `any` hides.
- An inherited interface with `Self` in its arguments, as in `interface Node: Link<Self>`. The table of an `any Node` would need a conformance of the value's type to `Link<any Node>`, which the type does not have. The message names the inherited interface: "it inherits `Link<Self>`, whose arguments name `Self`".

An interface that inherits another one has the requirements of both. The message names the interface that has the requirement: "`Sorted` cannot be used as `any Sorted`: it inherits `Ord`, whose `less` takes another `Self`". The compiler checks each interface of the group once, so a long chain of inheritance costs no more than its length.

A type parameter does not hide its type. Use a bound, `T: Eq`, where the code needs the requirement. The compiler makes one copy of the function for each type argument, so `Self` is always a known type.

`Display` and `AnyObject` can be `any`. So can an interface that has only methods that take `self` and use `Self` nowhere else, and so can a generic interface when its arguments are given: `any Convert<Kelvin>`.

## Broken

```sisu
fn main() {
    let x: any Eq = 5
    print(x)
}
```

## Fixed

```sisu
fn same<T: Eq>(a: T, b: T) -> bool {
    a == b
}

fn main() {
    print(same(5, 5))
}
```
