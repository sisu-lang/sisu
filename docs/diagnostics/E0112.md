# E0112: variant after a method

An enum lists its variants first, then its methods. A variant that follows the first method is an error. The second label points at that method.

## Why

One place to look for the variants: they are the first lines of the body, and the methods are the rest. Moving the variant above the first method fixes it. The compiler does not move code for you, so there is no fix.

## Broken

```sisu
enum Light {
    Red
    fn same(self) -> Light { self }
    Green
}

fn main() {
    print(Light.Red.same() == Light.Green)
}
```

## Fixed

```sisu
enum Light {
    Red
    Green

    fn same(self) -> Light { self }
}

fn main() {
    print(Light.Red.same() == Light.Green)
}
```
