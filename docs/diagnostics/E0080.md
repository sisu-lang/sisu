# E0080: `_` used as a name

A function, class, struct, field or parameter cannot be named `_`.

## Why

`_` is reserved for `let _` and `for _`, where it binds nothing. A function, class, struct, field or parameter named `_` could never be used, because `_` is not a value. The compiler cannot know which name was meant, so there is no fix.

## Broken

```sisu
fn _() {
    print(1)
}

fn main() {
}
```

## Fixed

```sisu
fn helper() {
    print(1)
}

fn main() {
    helper()
}
```
