# E0006: `else` on a line of its own

An `else` must stand on the same line as the `}` that closes the `if` before it.
The `else` of a `let ... else` must stand on the same line as the value of the `let`.

## Why

A line break after `}` ends the `if` statement, so an `else` at the start of the next line has nothing to belong to. Sisu has one layout, `} else {`, so a reader sees at once that the two blocks belong together.

## Broken

```sisu
fn main() {
    let n = 3
    if n > 2 {
        print(1)
    }
    else {
        print(0)
    }
}
```

## Fixed

```sisu
fn main() {
    let n = 3
    if n > 2 {
        print(1)
    } else {
        print(0)
    }
}
```
