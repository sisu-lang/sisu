# E0083: word reserved for a later version

A reserved word cannot be a name or start an expression.

## Why

`import`, `pub`, `record`, `weak`, `test`, `extern` and `as` are reserved for a later version of Sisu. They are keywords now, so a program that uses one as a name does not break when its feature arrives. The word may sit where a name goes or where a later feature goes (`import x`), so the compiler cannot know what was meant, and there is no fix. Pick another name.

## Broken

```sisu
fn main() {
    let record = 1
}
```

## Fixed

```sisu
fn main() {
    let found = 1
    print(found)
}
```
