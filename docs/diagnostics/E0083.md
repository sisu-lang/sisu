# E0083: word reserved for a later version

A reserved word cannot be a name or start an expression.

## Why

Sisu reserves `import`, `pub`, `move`, `weak`, `test`, `extern` and `as` for a later version. They are keywords now, so a program that uses one as a name does not break when its feature arrives. The word may sit where a name goes or where a later feature goes (`import x`). The compiler cannot know what was meant, so there is no fix. Pick another name.

## Broken

```sisu
fn main() {
    let extern = 1
}
```

## Fixed

```sisu
fn main() {
    let found = 1
    print(found)
}
```
