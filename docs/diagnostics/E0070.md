# E0070: method called as a function

`len()`, `sum()` and `contains(x)` are methods of arrays: `xs.len()`, not `len(xs)`. Math is the same: `sqrt(x)`, `pow(x, 2)` and `max(a, b)` are the methods `x.sqrt()`, `x.pow(2)` and `a.max(b)`. The methods of your own classes and enums are the same: when `name` is a method of the class `Actual`, `name(self)` becomes `self.name()`. When no function of that name exists and the first argument has that method, the error offers the method call. A name that the first argument's type has no method for, such as `abs(n)` with `n: i64`, is [E0052](E0052.md).

The fix is safe when the method call takes the remaining arguments as written. For a method of your own, that means each remaining argument fits its parameter as `receiver.method(args)` checks it, and the method has no type parameters of its own. Otherwise it is unsafe, and the arguments still need fixing: `len(xs, 1)` becomes `xs.len(1)`, and `len()` takes no arguments. It is also unsafe when the rewrite would delete a comment inside the call.

## Why

These operations are methods, and Sisu has no built-in functions of the same names. Each belongs to the value it works on, so it is called on that value. You can still define a function of your own that takes an array or a number, even one named `len` or `sqrt`, and call it as a function.

## Broken

```sisu
fn main() {
    let xs = [1, 2, 3]
    print(len(xs))
}
```

## Fixed

```sisu
fn main() {
    let xs = [1, 2, 3]
    print(xs.len())
}
```
