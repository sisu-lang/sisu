# E0060: `print` or `eprint` of an optional array

Status: retired in [ADR 0036](../adr/0036-every-type-prints-and-printing-an-optional-warns.md), in milestone 8. `print` and `eprint` take a value of every type but `unit` and `never`. A `never` value gives [E0061](E0061.md). An optional array compiles with the warning [W0015](W0015.md).

`print` and `eprint` write one value that is not an optional. An optional array is `None` or an array, so a program unwraps it first.

## Why

The optional can be `None`. The program decides what to print then.

## Broken

```sisu
fn main() {
    let xs: [i64]? = [1, 2, 3]
    print(xs)
}
```

## Fixed

```sisu
fn main() {
    let xs: [i64]? = [1, 2, 3]
    if let ys = xs {
        print(ys)
    }
}
```
