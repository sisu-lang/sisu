# E0060: `print` or `eprint` of an optional array

Status: retired in milestone 8, stage 5. `print` and `eprint` take a value of every type but `unit`, and an optional array is printed with the warning [W0015](W0015.md).

`print` and `eprint` write one value that is not an optional. An optional array is `None` or an array, so a program unwraps it first.

## Why

The optional can be `None`. The program decides what to print then.

## Broken

```sisu
fn main() {
    let xs: [i64]? = [1, 2, 3]
    print(xs)
}
```

## Fixed

```sisu
fn main() {
    let xs: [i64]? = [1, 2, 3]
    if let ys = xs {
        print(ys)
    }
}
```
