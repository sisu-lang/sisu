# E0141: `break` with a value in a loop that has none

Only a `loop` gives a value through `break`. A `break` with a value in a `for`, a `while` or a `while let` is an error.

## Why

A `for`, a `while` and a `while let` also end when their header says so: the source runs out, or the condition is false. That end gives no value, so the loop as a whole has none, and a value given by `break` would have nowhere to go. A `loop` ends only through a `break`, so each of its `break`s can give the value. To keep a value found in another loop, assign it to a variable declared before the loop, then `break`.

## Broken

```sisu
fn main() {
    let words = ["a", "bb", "ccc"]
    for w in words {
        if w.len() > 1 {
            break w
        }
    }
}
```

## Fixed

```sisu
fn main() {
    let words = ["a", "bb", "ccc"]
    let mut found = ""
    for w in words {
        if w.len() > 1 {
            found = w
            break
        }
    }
    print(found)
}
```
