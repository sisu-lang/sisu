# E0089: unknown escape

After a `\` a `char` or string literal takes one of `\n`, `\t`, `\r`, `\0`, `\\`, `\"`, `\'`, `\{`, `\}` or `\u{...}`. Any other character after the `\` is an error, reported over the `\` and that character.

## Why

An escape that Sisu does not know has no value. Choosing one would put a character in the program that the writer may not have meant, and there is no `\xNN` byte escape: a lone byte could break the UTF-8 that text must be. In a string literal the most likely mistake is a backslash meant as itself, so the report offers `\\` as an unsafe fix, which you check before you apply it. In a `char` literal a second backslash would make two code points, so none is offered.

## Broken

```sisu
fn main() {
    let c = '\q'
    print(c)
}
```

## Fixed

```sisu
fn main() {
    let c = '\t'
    print(c)
}
```
