# E0154: type that does not conform to an interface that is needed

A type must conform to an interface when another interface inherits it, or when a bound asks for it. An interface can inherit others: `interface Shape: Named` asks each type that conforms to `Shape` to conform to `Named` too. A conformance in the list of a class or an enum meets the inherited interfaces with the methods of its body. An `extend Square: Shape` block holds the methods of `Shape` only, so the inherited interface needs a conformance of its own.

## Why

A function that takes a `Shape` can use every requirement of `Named` on it. The type must conform to `Named` for that to work. Add a conformance to the inherited interface: in the list of the class, or in an `extend Square: Named` block.

## Broken

```sisu
interface Named {
    fn name(self) -> string
}

interface Shape: Named {
    fn area(self) -> f64
}

class Square {
    side: f64
}

extend Square: Shape {
    fn area(self) -> f64 {
        self.side * self.side
    }
}

fn main() {
    print(Square(side: 2.0).area())
}
```

## Fixed

```sisu
interface Named {
    fn name(self) -> string
}

interface Shape: Named {
    fn area(self) -> f64
}

class Square {
    side: f64
}

extend Square: Named {
    fn name(self) -> string {
        "square"
    }
}

extend Square: Shape {
    fn area(self) -> f64 {
        self.side * self.side
    }
}

fn main() {
    print(Square(side: 2.0).area())
}
```

## Bounds

A bound `T: Shape` asks each type argument for `T` to conform to `Shape`. The compiler checks the bound where a type argument meets it: in a call of a generic function or method, in a construction of a class or a variant, and in each type that names a class or an enum with a bound, such as the type of a local, a parameter, a field or a payload. The error points at the argument or the type that fails, and its second label shows the bound. A call that fails gives one error, and the callee's body adds none.

When the failing type is a type parameter of the function that you write, add the bound to it. The help shows the parameter with the bounds that it has, and the new one: `add a bound: T: Named & Same`. The help is not shown for an interface that takes type parameters.
