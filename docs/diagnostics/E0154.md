# E0154: conformance that needs another conformance

An interface can inherit others: `interface Shape: Named` asks each type that conforms to `Shape` to conform to `Named` too. A conformance in the list of a class or an enum meets the inherited interfaces with the methods of its body. An `extend Square: Shape` block holds the methods of `Shape` only, so the inherited interface needs a conformance of its own.

## Why

A function that takes a `Shape` can use every requirement of `Named` on it. The type must conform to `Named` for that to work. Add a conformance to the inherited interface: in the list of the class, or in an `extend Square: Named` block.

## Broken

```sisu
interface Named {
    fn name(self) -> string
}

interface Shape: Named {
    fn area(self) -> f64
}

class Square {
    side: f64
}

extend Square: Shape {
    fn area(self) -> f64 {
        self.side * self.side
    }
}

fn main() {
    print(Square(side: 2.0).area())
}
```

## Fixed

```sisu
interface Named {
    fn name(self) -> string
}

interface Shape: Named {
    fn area(self) -> f64
}

class Square {
    side: f64
}

extend Square: Named {
    fn name(self) -> string {
        "square"
    }
}

extend Square: Shape {
    fn area(self) -> f64 {
        self.side * self.side
    }
}

fn main() {
    print(Square(side: 2.0).area())
}
```
