# E0033: name that is not in scope

A name in an expression must be a binding in scope: a `let`, a parameter, or a binding made by `for`, `if let` or `while let`. A binding is in scope from its declaration to the end of its block.

The name of a type is no binding: `f64` or a class's name read as a value is [E0105](E0105.md). So is the name of a function read as a value.

When a binding in scope has a similar name, the error offers it as an unsafe fix. The unsafe fix may be wrong: the name could be a binding that was never declared.

## Why

Sisu does not resolve a misspelled name on its own. A misspelled name, or one used after its block has ended, would otherwise read some other value or none.

## Broken

```sisu
fn main() {
    let total = 3
    print(totl)
}
```

## Fixed

```sisu
fn main() {
    let total = 3
    print(total)
}
```
