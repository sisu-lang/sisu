# E0019: `mut` parameter

Status: retired in [ADR 0043](../adr/0043-mut-parameters-copy-in-and-out.md).

A parameter cannot be `mut`. It keeps the value it was passed.

## Why

A parameter that changed would look like a change to the caller's value, which it never is ([ADR 0011](../adr/0011-let-mut-marks-what-can-change.md)). Copy the parameter into a `let mut` variable and change the copy.

## Broken

```sisu
fn add_one(mut n: i64) -> i64 {
    n += 1
    n
}

fn main() {
    print(add_one(1))
}
```

## Fixed

```sisu
fn add_one(n: i64) -> i64 {
    let mut total = n
    total += 1
    total
}

fn main() {
    print(add_one(1))
}
```
