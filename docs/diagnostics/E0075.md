# E0075: base prefix in upper case

A number in another base starts with a lower case prefix: `0x` for hexadecimal, `0b` for binary and `0o` for octal. `0X1F`, `0B1` and `0O7` are errors.

## Why

One spelling per prefix keeps code uniform, and an upper case `O` next to a `0` is easy to misread. The fix lower-cases the prefix and nothing else, so it is safe. The one exception is a value of magnitude 2^63, such as `0X8000_0000_0000_0000`: it is valid only after a `-`, so there the fix is unsafe. A number that follows a `.` and is too large for an integer, such as `x.0XFFFFFFFFFFFFFFFFFFFF`, gets no fix, because the parser rejects its lower case form.

## Broken

```sisu
fn main() {
    let n = 0X1F
    print(n)
}
```

## Fixed

```sisu
fn main() {
    let n = 0x1F
    print(n)
}
```
