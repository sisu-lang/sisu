# E0172: `else` block of a `let ... else` that can finish

A `let ... else` runs its `else` block when the pattern does not match. The block must not finish: it must leave with `return`, `break`, `continue` or `panic(...)`.

## Why

After a `let ... else`, the program uses the names that the pattern binds. Those names exist only when the pattern matched. If the `else` block could finish, the program would go on to the next line with no value in the names. The block has the type `never`, as `return` does, so the next line always sees a matched pattern.

The report points at the `}` that ends the block. A block that ends in a call of `panic`, in a `while true` with no `break`, or in an `if` or a `match` whose branches all leave, does not finish. An empty block, a block that ends in a plain statement, and an `if` with no `else` can finish.

## Broken

```sisu
fn main() {
    let o: i64? = None
    let v = o else { print(1) }
    print(v)
}
```

## Fixed

```sisu
fn main() {
    let o: i64? = None
    let v = o else {
        print(1)
        return
    }
    print(v)
}
```
