# E0014: optional of an optional

A type takes at most one `?`. Optionals do not nest, so `i64??` is not a type.

## Why

`i64?` already holds either a number or `None`. A second `?` would add a second kind of nothing that no code could tell apart from the first.

## Broken

```sisu
fn main() {
    let x: i64?? = None
    print(1)
}
```

## Fixed

```sisu
fn main() {
    let x: i64? = None
    print(x ?? 1)
}
```
