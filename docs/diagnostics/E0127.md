# E0127: only a name here

A pattern at a class, array or `f64` position takes only a name, which binds the value, or `_`, which ignores it. Variants are not patterns there.

## Why

These types have no variants to tell apart. Bind the value and read its fields or test it inside the arm.

## Broken

```sisu
class Point {
    x: i64
}

enum Slot {
    Full(Point)
}

fn main() {
    let s = Slot.Full(Point(x: 1))
    let n = match s {
        Full(Point(x)) => x
    }
    print(n)
}
```

## Fixed

```sisu
class Point {
    x: i64
}

enum Slot {
    Full(Point)
}

fn main() {
    let s = Slot.Full(Point(x: 1))
    let n = match s {
        Full(p) => p.x
    }
    print(n)
}
```
