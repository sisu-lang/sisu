# E0167: `mut` argument for a parameter that is not `mut`

`mut` goes only before an argument for a `mut` parameter.

## Why

A `mut` argument shows that the callee can change the place that the argument names. When the parameter is not `mut`, the callee gets a copy and nothing is stored back, so the `mut` would tell the reader something false. This holds for built-in functions such as `print` too.

A constructor copies each value into a field of the new object or variant. Nothing is stored back to the argument there, so a constructor takes no `mut` argument, with `mut` before the label or before the value. A `mut` field can change after the object is made, and an enum value never changes after it is built.

The fix removes the `mut`.

## Broken

```sisu
fn plain(xs: [i64]) {
    print(xs)
}

fn main() {
    let mut xs = [1, 2]
    plain(mut xs)
    print(xs)
}
```

## Fixed

```sisu
fn plain(xs: [i64]) {
    print(xs)
}

fn main() {
    let mut xs = [1, 2]
    plain(xs)
    print(xs)
}
```
