# W0016: write to a copy that nothing reads

The warning is for a `let mut` that copies a place and is then only written to. A place is a name, a field or an element, such as `bank.accounts[i]`. The copy is a new value, so the writes change the copy and do not change the place. The program still builds. The warning is at the first write. Only live code is judged, as for [W0012](W0012.md). The warning does not show while the program has an error.

## Why

A struct or an array is copied when it is bound to a name. A program that writes `let mut a = bank.accounts[i]` and then `a.balance += 100` seems to add to the account, but the account does not change. Nothing reads the copy, so the writes are lost. The warning tells you to write to the place itself.

The warning is for a local when all of these hold:

- Its value is a place, and the place crosses no class object. A class field has its own `mut` rule. A slice, such as `xs[0..1]`, is not a place.
- The function writes to the local at least once.
- Each use of the local is a write to a field or an element, or a `push`. These are `a.balance = 1`, `a.balance += 100`, `a.xs[0] = 1` and `a.xs.push(1)`.
- No write crosses a class object. Such a write changes a shared object, so it has an effect.

Any other use rules out this warning. A read of any part, a `return` and a tail value are reads. A `mut` argument to a call with no result and a write of the whole local, `a = e`, are not reads, so [W0014](W0014.md) can still apply. A name that starts with `_` gets no warning, and neither does a `mut` parameter.

A `let mut` with a fresh value, such as `A(b: 1)`, and only these writes gets [W0014](W0014.md): it is never read.

The warning has help and no fix. The place can change between the `let` and a write, and an index is evaluated again at each write. So Sisu cannot show that a rewrite keeps the meaning of the program. The message quotes the place as written. When the place spans lines or holds a comment, the message names only its root. The help depends on the root of the place:

- A root that can change: write to the place itself.
- A `let`: delete the write, or make the root a `let mut` and write to the place.
- A plain parameter or a plain `self`: delete the write, or return the changed copy.
- A name that `for`, `if let`, `while let` or a `match` arm binds: delete the write.

## Broken

```sisu
struct Account { balance: i64 }

fn main() {
    let accounts = [Account(balance: 1)]
    let mut a = accounts[0]
    a.balance += 100
    print(accounts[0].balance)
}
```

## Fixed

```sisu
struct Account { balance: i64 }

fn main() {
    let mut accounts = [Account(balance: 1)]
    accounts[0].balance += 100
    print(accounts[0].balance)
}
```
