# W0009: `while` with the condition `true`

A `while` whose condition is the literal `true`, with or without parentheses, is a warning, and the program still builds. The fix writes `loop` in its place and keeps the loop label. A `while true` that a `break` with a value targets has no fix: the rewrite would remove that error ([E0141](E0141.md)) rather than fix it.

## Why

`loop` says the same thing, an endless loop that only `break`, `return` or a panic ends, and it is the one spelling for it. The two lower to the same code.

## Broken

```sisu
fn main() {
    let mut n = 0
    while true {
        n += 1
        if n == 3 {
            break
        }
    }
    print(n)
}
```

## Fixed

```sisu
fn main() {
    let mut n = 0
    loop {
        n += 1
        if n == 3 {
            break
        }
    }
    print(n)
}
```
