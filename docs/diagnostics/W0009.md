# W0009: `while` with the condition `true`

A `while` whose condition is the literal `true`, with or without parentheses, is a warning, and the program still builds. The fix writes `loop` in its place and keeps the loop label. The fix is withheld when a jump or loop label in the loop failed, as with a `break` with a value ([E0141](E0141.md)): the rewrite could remove that error rather than fix it.

## Why

`loop` says the same thing, an endless loop, and it is the one spelling for it. The two lower to the same code.

## Broken

```sisu
fn main() {
    let mut n = 0
    while true {
        n += 1
        if n == 3 {
            break
        }
    }
    print(n)
}
```

## Fixed

```sisu
fn main() {
    let mut n = 0
    loop {
        n += 1
        if n == 3 {
            break
        }
    }
    print(n)
}
```
