# E0131: `if let` or `while let` that always matches

The pattern of an `if let` or `while let` on an enum matches every value of the enum, so it tests nothing.

## Why

An `if let` whose pattern always matches never runs its `else`, and a `while let` whose pattern always matches never ends the loop. Either way the pattern only takes the value apart, which a `match` with one arm says plainly. "Always matches" is the coverage check `match` uses, so a pattern with a nested variant always matches too when that variant is the only one of its enum. When the pattern of an `if let` or a `let ... else` is a name or `_`, use a plain `let`: in a `let ... else`, remove the `else` block.

## Broken

```sisu
enum Pair {
    P(i64, i64)
}

fn main() {
    let p = Pair.P(1, 2)
    if let P(a, b) = p {
        print(a + b)
    }
}
```

## Fixed

```sisu
enum Pair {
    P(i64, i64)
}

fn main() {
    let p = Pair.P(1, 2)
    match p {
        P(a, b) => print(a + b)
    }
}
```
