# E0153: second conformance to an interface

A type conforms to an interface once. A class that lists the interface after its name already conforms, and so does the type of an `extend Circle: Shape` block. A second conformance to the same interface is an error.

This is also true of an interface that the compiler writes. `class Circle: Display, Display` and `enum Light: Eq` with `extend Light: Eq {}` list the interface twice. Remove one of them.

When the second conformance writes the methods, the first gets no [E0152](E0152.md) for them: remove the listing, or move the methods into the type and then remove the block.

A call of a method that only the second block writes gets no [E0063](E0063.md) beside this error. The compiler does not check the methods of the second block against the interface until you remove one of the two conformances.

## Why

Two conformances of one type to one interface give two answers to a call through the interface, and Sisu has no rule to choose between them. Keep one of them. If the two blocks hold different methods, move the methods that you want into the one you keep.

A generic interface can have several conformances for one type, if their type arguments differ. `extend Celsius: Convert<Fahrenheit>` and `extend Celsius: Convert<Kelvin>` are two conformances. Two blocks with the same type arguments clash, and the error shows them: `Celsius` conforms to `Convert<Kelvin>` twice. The type arguments of the interface count in the same way as the target. `extend<T> Box<T>: Convert<T>` and `extend<U> Box<U>: Convert<i64>` clash on `Box<i64>: Convert<i64>`. `extend<U> Box<U>: Convert<[U]>` does not clash with `extend<T> Box<T>: Convert<T>`, as no `T` can be `[T]`.

Two conformances clash when one type fits both targets. `extend<T> Stack<T>: Named` and `extend Stack<i64>: Named` clash on `Stack<i64>`, and the error names that type. `extend<T> Pair<T, i64>: Named` and `extend<U> Pair<i64, U>: Named` clash on `Pair<i64, i64>`. Two blocks that no type fits together, such as `extend<T> Pair<T, [T]>: Named` and `extend<U> Pair<[U], U>: Named`, do not clash.

## Broken

```sisu
interface Shape {
    fn area(self) -> f64
}

class Circle: Shape {
    r: f64

    fn area(self) -> f64 {
        3.0 * self.r * self.r
    }
}

extend Circle: Shape {
    fn area(self) -> f64 {
        0.0
    }
}

fn main() {
    print(Circle(r: 1.0).area())
}
```

## Fixed

```sisu
interface Shape {
    fn area(self) -> f64
}

class Circle: Shape {
    r: f64

    fn area(self) -> f64 {
        3.0 * self.r * self.r
    }
}

fn main() {
    print(Circle(r: 1.0).area())
}
```
