# E0132: range written another language's way

A range is written `a..b`, which leaves out `b`, or `a..=b`, which includes it. Sisu has no `a..<b` and no `a...b`.

## Why

`..` already leaves out its end in a `for` loop, so an inclusive `..`, as some languages spell it, would change the loops that exist; Rust's `..=` adds the inclusive form without that. Both work in a `for` loop and in a pattern. `0..<n` means what `0..n` means, so the fix deletes the `<`. `1...5` could mean `1..=5` or `1..5`, so the report names both and offers no fix.

## Broken

```sisu
fn main() {
    for i in 0..<3 {
        print(i)
    }
}
```

## Fixed

```sisu
fn main() {
    for i in 0..3 {
        print(i)
    }
}
```
