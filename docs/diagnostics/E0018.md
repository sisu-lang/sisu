# E0018: `mut self` on a class method

A method of a class takes `self`, never `mut self`. A method of an `extend` block of a class follows the same rule. This error is for a class only. A method of a struct or of an enum can take `mut self`, and so can an interface requirement ([Structs](../reference/structs.md#mut-self)). A class meets a `mut self` requirement with plain `self`.

## Why

An object is shared, so `self` can already write every `mut` field of the class. A `mut self` would suggest that the method could replace the object, which no method can do. Removing the `mut` is a safe fix when `self` is the whole parameter.

When `self` has a type, as in `mut self: i64`, the fix also removes the type, because `self` takes none.

## Broken

```sisu
class Counter {
    mut n: i64

    fn bump(mut self) {
        self.n += 1
    }
}

fn main() {
    let c = Counter(n: 0)
    c.bump()
    print(c.n)
}
```

## Fixed

```sisu
class Counter {
    mut n: i64

    fn bump(self) {
        self.n += 1
    }
}

fn main() {
    let c = Counter(n: 0)
    c.bump()
    print(c.n)
}
```
