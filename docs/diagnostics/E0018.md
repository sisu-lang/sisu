# E0018: `mut self` on a method

A method of a class or an enum takes `self`, never `mut self`.

## Why

An object is shared, so `self` can already write every `mut` field of the class. A `mut self` would suggest that the method could replace the object, which no method can do. An enum value never changes, so `mut self` on an enum method has nothing to mean; the help is to return a new value. Removing the `mut` is an unsafe fix there, since the body may still assign `self`.

## Broken

```sisu
class Counter {
    mut n: i64

    fn bump(mut self) {
        self.n += 1
    }
}

fn main() {
    let c = Counter(n: 0)
    c.bump()
    print(c.n)
}
```

## Fixed

```sisu
class Counter {
    mut n: i64

    fn bump(self) {
        self.n += 1
    }
}

fn main() {
    let c = Counter(n: 0)
    c.bump()
    print(c.n)
}
```
