# E0140: instantiations that never end

A generic function, class or enum cannot use itself with a type argument that grows, directly or through other declarations: `f([x])` inside `fn f<T>(x: T)` calls `f` with `[T]` for `T`, and a field of type `Nest<[T]>` inside `Nest<T>` does the same for a type.

## Why

Each set of type arguments a program uses gets its own compiled copy of the declaration. A copy for `i64` that uses one for `[i64]`, which uses one for `[[i64]]`, would need copies without end, so the compiler reports the cycle instead. A use with the same arguments, such as `f(x)` inside `f`, needs no new copy, and a growing use that never comes back to its declaration, such as `g([x])` in `f` for a `g` that does not use `f`, needs one.

A call through a bound can close a cycle too. A call `t.wrap(x)` on a type parameter calls the method of each type that `wrap` can reach, so the argument of the call counts as an argument of each of those methods. When one of them calls the function again with a longer argument, as `go(self, [x])` does, the instantiations never end.

A conformance can close a cycle too. A call `x.run()` on a type parameter can reach the method of every type that conforms to the interface, so the compiler counts a call through `Run` as a call of each of them. A conformance for a type like `Box<T>` takes one level off the type, as the receiver of the call is a `Box<T>` and the method knows `T`. When a method of `Box<T>` calls a function that calls `run` again with a `Box<Box<T>>`, the type grows by two levels and shrinks by one, and the instantiations never end. The error names the method that the cycle runs, and says that the call counts as reaching every conformance. The rule is cautious: it cannot see which conformance a call reaches, so it can report a cycle that would stop.

An operator can close a cycle too. `==` on a class or an enum with a written `eq` calls that `eq`, and `==` on an array, an optional or an enum calls the `eq` of each type inside it. In a generic body, the compiler counts `==`, `<` and `contains` on a type that names a type parameter as a call through `Eq` or `Ord`, which reaches every conformance. When the `eq` of `W<T>` compares two values of type `W<[T]>`, the type grows, and the instantiations never end. An array or an optional of `T` has its levels taken off first, as the compiler writes its `eq` and adds no growth by itself.

`print` can close a cycle in the same way. `print` of a class or an enum with a written `to_string` calls that `to_string`, and `print` of an array, an optional or an enum calls the `to_string` of each type inside it. In a generic body, the compiler counts `print` of a type that names a type parameter as a call through `Display`. When the `to_string` of `W<T>` prints a value of type `W<[T]>`, the type grows, and the instantiations never end.

An associated type can close a cycle. A value of type `S.Item` is the type that the conformance of `S` chose for `Item`, and a choice such as `Chain<Chain<Chain<T>>>` is a type that has more levels than its target `Chain<T>`. A function that passes an `S.Item` on, or calls a method of one, instantiates itself with a longer type, and the instantiations never end. A choice that names no type parameter, as `type Child = Dir`, does not grow, so a call with an `S.Child` is fine. The growth of a choice that names another associated type is counted with the growth of that type.

A field that holds an associated type can close a cycle too. A field of type `T.Item` holds the type that the conformance of `T` chose for `Item`. When that choice names the class or enum again with a longer type argument, as `type Item = E<W<W<T>>>` does for the enum `E<T: I>` that holds `T.Item`, the type grows with each use, and the instantiations never end. The error shows the choice, and a note shows the field. A choice that names the type with the same or a shorter argument, or that names no type parameter, does not grow.

## Broken

```sisu
fn nest<T>(x: T, n: i64) {
    if n > 0 {
        nest([x], n - 1)
    }
}

fn main() {
    nest(1, 3)
}
```

## Fixed

```sisu
fn nest<T>(x: T, n: i64) {
    if n > 0 {
        nest(x, n - 1)
    }
}

fn main() {
    nest(1, 3)
}
```
