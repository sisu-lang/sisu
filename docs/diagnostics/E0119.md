# E0119: variant built the wrong way

A variant that holds nothing is written without parentheses: `State.Idle`, not `State.Idle()`. A variant with a payload is always called with it: `State.Running(5)`, not `State.Running`.

## Why

One spelling for each variant means a reader can tell from `State.Idle` alone that it holds nothing, and from `State.Running(5)` that it holds a value. The fix for empty parentheses is certain, so it is safe; with arguments inside, it deletes them too, so it is unsafe. A missing payload has no fix, since only you know its value.

## Broken

```sisu
enum State {
    Idle
    Running(i64)
}

fn main() {
    let _ = State.Idle()
    let _ = State.Running(5)
}
```

## Fixed

```sisu
enum State {
    Idle
    Running(i64)
}

fn main() {
    let _ = State.Idle
    let _ = State.Running(5)
}
```
