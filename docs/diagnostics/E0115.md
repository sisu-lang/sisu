# E0115: enum without variants

An enum needs at least one variant.

## Why

A value of an enum is one of its variants, so an enum with none has no values at all, and nothing could use it. The variants are yours to name, so there is no fix.

## Broken

```sisu
enum Empty {}

fn main() {
    print(1)
}
```

## Fixed

```sisu
enum Signal {
    Go
}

fn main() {
    let s = Signal.Go
    print(s == Signal.Go)
}
```
