# E0016: `let` in front of a field

A field is written `name: Type`, or `mut name: Type` when it can change. It takes no `let`.

## Why

`let` declares a binding in a block. A field belongs to the class, and `mut` alone says whether it can change ([ADR 0011](../adr/0011-let-mut-marks-what-can-change.md)).

## Broken

```sisu
class Point {
    let x: i64
    y: i64
}

fn main() {
    let p = Point(x: 1, y: 2)
    print(p.x + p.y)
}
```

## Fixed

```sisu
class Point {
    x: i64
    y: i64
}

fn main() {
    let p = Point(x: 1, y: 2)
    print(p.x + p.y)
}
```
