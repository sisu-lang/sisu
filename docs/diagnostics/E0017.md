# E0017: method without `self`

A function inside a class or a struct is a method, and its first parameter is `self`.

## Why

Sisu has no static methods yet, so every function in a class, an enum or a struct acts on a value of the type. Write a function that needs no such value outside the type.

## Broken

```sisu
class Counter {
    mut n: i64

    fn reset() {
        print(0)
    }
}

fn main() {
    let c = Counter(n: 5)
    c.reset()
    print(c.n)
}
```

## Fixed

```sisu
class Counter {
    mut n: i64

    fn reset(self) {
        self.n = 0
    }
}

fn main() {
    let c = Counter(n: 5)
    c.reset()
    print(c.n)
}
```
