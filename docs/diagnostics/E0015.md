# E0015: `,` between fields, variants or arms

Each field of a class, each variant of an enum and each arm of a `match` stands on its own line. A `;` can stand in for the line break, but a `,` cannot.

## Why

A line break separates the members of a class or an enum and the arms of a `match`, as it separates statements. Fields, variants or arms written with commas would be a second way to say the same thing. The fix keeps the separator and changes the comma: a `,` in the middle of a line becomes `;`, and a `,` at the end of a line goes, because a `;` there would be unnecessary.

## Broken

```sisu
class Point {
    x: i64, y: i64
}

fn main() {
    print(1)
}
```

## Fixed

```sisu
class Point {
    x: i64
    y: i64
}

fn main() {
    print(1)
}
```
