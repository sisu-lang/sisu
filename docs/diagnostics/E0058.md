# E0058: field called as a method

A field is read without `()`: `s.side`. With `()`, `s.side()` calls a method, and the class or the struct has no method of that name.

## Why

A field holds a value, not code to run, so a field cannot be called.

## Broken

```sisu
class Square {
    side: i64
}

fn main() {
    let s = Square(side: 2)
    print(s.side())
}
```

## Fixed

```sisu
class Square {
    side: i64
}

fn main() {
    let s = Square(side: 2)
    print(s.side)
}
```
