# E0116: local named like an enum or an optional type

A local, a parameter or a binding cannot take the name of an enum: `let Shape = 1` is an error when `Shape` is an enum. A type alias of an enum has the same rule: with `type Form = Shape`, `let Form = 1` is an error. So is a local named like an alias of an optional type, such as `type Maybe = i64?` and `let Maybe = 1`, because `Maybe.Some(1)` and `Maybe.None` would read the alias. The message for an enum, or an alias of one, is "`Shape` names an enum". The message for an alias of an optional type is "`Maybe` names an optional type".

## Why

`Shape.Circle` builds a variant of the enum `Shape`. If a local could take the name `Shape`, the same text could mean a method call on that local, and a reader would have to look for the binding to know which. A rule that rejects the name now can be relaxed later; a shadowing rule cannot be taken back. There is no fix, since the new name is yours to choose.

## Broken

```sisu
enum Shape {
    Dot
}

fn main() {
    let Shape = Shape.Dot
    print(Shape == Shape.Dot)
}
```

## Fixed

```sisu
enum Shape {
    Dot
}

fn main() {
    let shape = Shape.Dot
    print(shape == Shape.Dot)
}
```
