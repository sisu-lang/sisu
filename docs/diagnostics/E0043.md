# E0043: expression without a value

An expression whose value is used must have one. A call of a function that returns nothing has none, and neither has an `if` without an `else`. An expression that never finishes, such as an `if` whose branches all `return`, has none either. Nor has a bare `break` in a `loop` whose other `break`s give it a value.

## Why

A `let`, an argument, an operand or a condition needs a value to work with. Nothing is left to bind when the expression returns nothing, or never returns.

## Broken

```sisu
fn greet() {
    print(1)
}

fn main() {
    let x = greet()
    print(x)
}
```

## Fixed

```sisu
fn one() -> i64 {
    1
}

fn main() {
    let x = one()
    print(x)
}
```
