# E0139: operator on a value of a type parameter

A value whose type is a type parameter `T`, or names one, as `[T]` does, has no operators: no `<`, no `==`, no `+` and no `-`. `contains` on a `[T]` compares elements with `==`, so it is not there either.

## Why

`T` may stand for any type, and not every type has every operator: a class has no `<`, and an array has no `+`. Type parameters cannot yet say what their types must have, so a generic function may only move such values around: pass them, return them, and put them into fields, arrays and optionals. To compare or compute, write the function for the type it needs.

## Broken

```sisu
fn smaller<T>(a: T, b: T) -> bool {
    a < b
}

fn main() {}
```

## Fixed

```sisu
fn smaller(a: i64, b: i64) -> bool {
    a < b
}

fn main() {
    print(smaller(1, 2))
}
```
