# E0145: loop label on something that is not a loop

Only `loop`, `while`, `while let` and `for` take a loop label. A `name:` before `if`, `match` or a block is an error, and so is a loop label named `_`, whose fix deletes it.

## Why

A loop label lets a `break` or `continue` name its loop, and an `if`, a `match` or a block has no `break` of its own. To leave a block early, move it into a function and `return`, or into a `loop` that ends with `break`. `_` means "no name" in Sisu, and a loop label that no jump can name has no use, so `_:` is deleted.

## Broken

```sisu
fn main() {
    let ready = true
    check: if ready {
        print("ready")
    }
}
```

## Fixed

```sisu
fn main() {
    let ready = true
    if ready {
        print("ready")
    }
}
```
