# E0108: malformed format spec

A format spec, the part of an interpolation after its `:`, is `#`, or `[<^>][width][.precision]`: an optional alignment, an optional width, and an optional `.` with the number of decimals. A spec without `#` must hold a width or a precision, and a `.` needs digits after it. `{x:}`, `{x:>}`, `{x:.}` and `{x:8.}` are errors. The error points at the spec, from its `:`.

## Why

An alignment alone, as in `{x:>}`, aligns nothing, and a `.` without digits names no precision. Each of these is half of a spec, and Sisu cannot tell which half is missing, so there is no fix: write the width or the precision you meant, or remove the `:` and what follows it.

## Broken

```sisu
fn main() {
    let x = 2.5
    print("{x:8.}")
}
```

## Fixed

```sisu
fn main() {
    let x = 2.5
    print("{x:8.2}")
}
```
