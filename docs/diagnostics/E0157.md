# E0157: bound that gives too many interfaces

A bound `T: Shape` gives a value of type `T` the requirements of `Shape` and of each interface that `Shape` inherits. The compiler lists these interfaces, each with its type arguments, where the bound is declared, and again for every function that has the bound. The list of one bound holds at most 256 interfaces. The lists of two bounds on one type parameter count apart. A bound that gives more is this error, and the compiler does not read its inherited interfaces further. The type parameter is then unknown: the compiler reports the bound, and nothing that depends on it.

An interface in the list of a class or an enum, and an interface in an `extend` block, are read the same way. For `class K: Wide`, where `Wide` gives more than 256 interfaces, the error is on `Wide`, and says "the conformance `K: Wide` gives more than 256 inherited interfaces". The conformances of `K` are then unknown, and the compiler reports no more about them.

## Why

An interface can inherit the same interface twice with different type arguments. `interface L1<A, B>: L0<A, B>, L0<i64, B>` is an example. Each level of such inheritance multiplies the number of interfaces, so a few levels give thousands of entries, and each function with the bound would have to read them all. The limit keeps the compile time small. A program that needs so many inherited interfaces can inherit fewer of them, or give the bound a smaller interface.

## Broken

```sisu
interface L0<A, B, C, D, E> {}

interface L1<A, B, C, D, E>: L0<A, B, C, D, E>, L0<i64, B, C, D, E>, L0<f64, B, C, D, E>, L0<A, i64, C, D, E>, L0<A, f64, C, D, E>, L0<A, B, i64, D, E>, L0<A, B, f64, D, E>, L0<A, B, C, i64, E>, L0<A, B, C, f64, E>, L0<A, B, C, D, i64>, L0<A, B, C, D, f64> {}

interface L2<A, B, C, D, E>: L1<A, B, C, D, E>, L1<i64, B, C, D, E>, L1<f64, B, C, D, E>, L1<A, i64, C, D, E>, L1<A, f64, C, D, E>, L1<A, B, i64, D, E>, L1<A, B, f64, D, E>, L1<A, B, C, i64, E>, L1<A, B, C, f64, E>, L1<A, B, C, D, i64>, L1<A, B, C, D, f64> {}

interface L3<A, B, C, D, E>: L2<A, B, C, D, E>, L2<i64, B, C, D, E>, L2<f64, B, C, D, E>, L2<A, i64, C, D, E>, L2<A, f64, C, D, E>, L2<A, B, i64, D, E>, L2<A, B, f64, D, E>, L2<A, B, C, i64, E>, L2<A, B, C, f64, E>, L2<A, B, C, D, i64>, L2<A, B, C, D, f64> {}

interface L4<A, B, C, D, E>: L3<A, B, C, D, E>, L3<i64, B, C, D, E>, L3<f64, B, C, D, E>, L3<A, i64, C, D, E>, L3<A, f64, C, D, E>, L3<A, B, i64, D, E>, L3<A, B, f64, D, E>, L3<A, B, C, i64, E>, L3<A, B, C, f64, E>, L3<A, B, C, D, i64>, L3<A, B, C, D, f64> {}

fn need<T: L0<string, string, string, string, string>>(_item: T) {}

fn use<T: L4<string, string, string, string, string>>(x: T) {
    need(x)
}

fn main() {
    print(1)
}
```

## Fixed

```sisu
interface L0<A, B, C, D, E> {}

interface L1<A, B, C, D, E>: L0<A, B, C, D, E>, L0<i64, B, C, D, E>, L0<f64, B, C, D, E>, L0<A, i64, C, D, E>, L0<A, f64, C, D, E>, L0<A, B, i64, D, E>, L0<A, B, f64, D, E>, L0<A, B, C, i64, E>, L0<A, B, C, f64, E>, L0<A, B, C, D, i64>, L0<A, B, C, D, f64> {}

fn need<T: L0<string, string, string, string, string>>(_item: T) {}

fn use<T: L1<string, string, string, string, string>>(x: T) {
    need(x)
}

class K: L1<string, string, string, string, string> {}

fn main() {
    use(K())
}
```
