# E0155: `extend` of a type that is not a class or an enum

An `extend` block adds methods to a class or an enum. It cannot extend a built-in type, such as `i64` or `[i64]`, or a type parameter.

## Why

Only the prelude adds methods to a built-in type. A program that extends one could change what every other program means by `i64`. To add behavior to a number, write a function, or wrap the number in a class. A type parameter stands for a different type at each use, so a block cannot add methods to it. Write an interface for what the type parameter must do, and use it as a bound.

A type parameter of the block must appear in its target, because a call finds the type of the parameter from the receiver. In `extend<T> Meters`, no receiver gives `T` a type. Remove the unused parameter.

## Broken

```sisu
extend i64 {
    fn double(self) -> i64 {
        self * 2
    }
}

fn main() {
    print(1)
}
```

## Fixed

```sisu
class Meters {
    value: i64
}

extend Meters {
    fn double(self) -> i64 {
        self.value * 2
    }
}

fn main() {
    print(Meters(value: 1).double())
}
```
