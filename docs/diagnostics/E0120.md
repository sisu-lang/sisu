# E0120: variant or method used as the other

An enum's variants are built through the enum, `Expr.Num(1)`, and its methods are called on a value, `e.eval()`. A variant called on a value, or a method named through the enum, is an error.

## Why

Sisu has one way to build a variant and one way to call a method, so `Expr.eval` never reads as a function value and `e.Num(1)` never reads as a method. The error names the form that works; there is no fix, since the value to call the method on is yours to choose.

## Broken

```sisu
enum Expr {
    Num(i64)
}

fn make(e: Expr) -> Expr {
    e.Num(1)
}

fn main() {
    match make(Expr.Num(0)) {
        Num(n) => print(n)
    }
}
```

## Fixed

```sisu
enum Expr {
    Num(i64)
}

fn make(e: Expr) -> Expr {
    Expr.Num(1)
}

fn main() {
    match make(Expr.Num(0)) {
        Num(n) => print(n)
    }
}
```
