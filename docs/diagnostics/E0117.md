# E0117: variant without its enum

A variant is named through its enum: `Expr.Num(2)` and `State.Idle`, not `Num(2)` or `Idle`. This error fires when no function, class, struct, constant or binding takes the name, but an enum has a variant of it.

## Why

A variant lives inside its enum, so two enums can each have an `Idle`. A class, a struct or a function can also take the name `Num` beside a variant `Expr.Num`. Writing the enum's name says which one you mean. When exactly one enum has the variant, the fix inserts its name. There is no fix when a `.` follows type arguments, because `Holder.W<i64>.x` does not parse. When several enums have the variant, you choose.

## Broken

```sisu
enum Expr {
    Num(i64)
}

fn main() {
    let _ = Num(2)
}
```

## Fixed

```sisu
enum Expr {
    Num(i64)
}

fn main() {
    let _ = Expr.Num(2)
}
```
