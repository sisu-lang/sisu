# E0124: `match` on a type it cannot take

`match` takes an enum, an optional, an integer, a `bool`, a `char` or a `string`. A class, an array or an `f64` is not one of them.

## Why

A pattern names a variant or a value that the program can compare exactly. A class has no variants, and an `f64` does not compare exactly. Read the class's fields.

## Broken

```sisu
class Point {
    x: i64
    y: i64
}

fn main() {
    let p = Point(x: 1, y: 2)
    let n = match p {
        _ => 0
    }
    print(n)
}
```

## Fixed

```sisu
class Point {
    x: i64
    y: i64
}

fn main() {
    let p = Point(x: 1, y: 2)
    let n = match p.x {
        1 => p.y
        _ => 0
    }
    print(n)
}
```
