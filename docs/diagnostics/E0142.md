# E0142: loop label that is also a name in scope

A loop label may not have the same name as a binding, a function, a constant, a class, an enum or a built-in type that is in scope where a `break` or `continue` names it. After `break`, a loop label may not be followed by a token that only continues an expression, such as `+` or `.`, or by a `(` or `[` that touches it.

## Why

After `break`, a name that is the loop label of a loop around the jump is the loop label, and what follows it is the value. A reader who also knows the name as a value cannot tell which one `break search` means, and `break search(i)` would leave the loop labeled `search` with the value `(i)` rather than call the function. Rename the loop label. To give a value in parentheses or an array, put a space after the loop label: `break outer (x)`, `break outer [1, 2]`.

## Broken

```sisu
fn search(n: i64) -> i64 {
    n * 2
}

fn main() {
    let found = search: loop {
        for i in 0..10 {
            if i == 3 {
                break search(i)
            }
        }
    }
    print(found)
}
```

## Fixed

```sisu
fn search(n: i64) -> i64 {
    n * 2
}

fn main() {
    let found = outer: loop {
        for i in 0..10 {
            if i == 3 {
                break outer search(i)
            }
        }
    }
    print(found)
}
```
