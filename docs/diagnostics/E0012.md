# E0012: `;` at the end of a statement

Status: retired in [ADR 0028](../adr/0028-a-semicolon-stands-in-for-a-line-break.md), after milestone 7. A `;` now separates two things on one line, and any other `;` is [W0007](W0007.md), a warning.

A statement ends at the end of its line. Sisu uses `;` only inside an array, in `[value; length]`.

## Why

A line break already ends a statement, so a `;` after a statement is never needed. Reporting it keeps one way to write a program. When only the `;` is in the way, the report offers to remove it. When another statement follows on the same line, put that statement on its own line.

## Broken

```sisu
fn main() {
    let x = 1;
    print(x)
}
```

## Fixed

```sisu
fn main() {
    let x = 1
    print(x)
}
```
