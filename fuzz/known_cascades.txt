# The known cascades of the single-mistake check of the program fuzzer.
# A cascade (GLOSSARY.md) is an error that follows from a guess about code that failed.
# Here it is an error that an injected mistake gives besides its own errors.
# Each line is a pair `<kind> <code>`: the kind of the mistake and the code of the extra error.
# The kinds are literal, callee, local, argument, declaration and duplicate.
# A pair in this file passes. A pair that is not in this file fails the single-mistake check.
# The nightly summary reports each pair that no input of the run gave.
# A checker fix removes pairs from this file. Only a new cascade that a fuzz run finds adds one.
# A comment line starts with `#` in its first column. A pair line has no comment after it.
# Any other line that is not empty stops the fuzzer with its number.
#
# Repro: `break yy` with an unknown name gives E0033 at `yy` and E0050 at `None`.
#   fn main() {
#       let zz: i64? = 1
#       let a = loop { if true { break yy }
#   break None }
#   }
local E0050

# The kind `duplicate` writes a top-level item twice. The checker then has no type for the name, or
# two definitions of it. So a use of the name gives a second error. Each pair below has this cause.
#
# The fixed seeds 15, 21, 89 and 112 give this pair. A call of a function that is defined twice has
# no type, so the negation of the call has the type `i64`, which gives E0032 where `f64` is needed.
#   fn r() -> f64 { 1.0 }
#   fn r() -> f64 { 1.0 }
#   fn g(x: f64) {}
#   fn main() { g(-r()) }
duplicate E0032

#   fn r() -> f64 { 1.0 }
#   fn main() {
#       let one = -r()

duplicate E0063
