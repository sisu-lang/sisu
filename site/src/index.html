Sisu Sisu is a small, statically typed language that compiles to native x86-64 code through LLVM.
Early and experimental · x86-64 Linux only

Sisu learns from the languages we admire.

Python shows that code can be simple and easy to read. Rust shows that a compiler can rule out whole kinds of bugs. Swift shows that memory can be safe without a garbage collector. Sisu brings these lessons together in one small, statically typed language that compiles to native code.

What Sisu takes from each language

From Python

Readability

  • Minimal syntax
  • One obvious way to do a thing

From Rust

Correctness

  • Immutable by default
  • Invalid states are unrepresentable
  • No null: optionals instead
  • Error messages that help you fix the code

From Swift

Memory safety, simply

  • Reference counting: no garbage collector, no borrow checker

What Sisu values, in order

When two values pull apart, the higher one wins.

  1. Correctness

    The language makes wrong programs hard to write. Mistakes are caught early, at compile time where possible.

  2. Simplicity

    Few concepts, rules without special cases, every effect visible where it happens.

  3. Readability

    Code that reads top to bottom. Errors in plain words.

  4. Performance

    Native code with predictable memory. Optimizations never change what a program means.

How a program becomes native code

sisuc turns one source file into one executable. Each stage hands the next a simpler form of the program.

  1. Lexertext → tokensSplits the UTF-8 source into names, numbers and symbols.
  2. Parsertokens → ASTBuilds the syntax tree: the program as you wrote it.
  3. CheckerAST → TIRResolves every name and types every expression. Rewrites shorthand such as for and ?? into simpler forms, and reports every error in one run. Its output is the typed tree, TIR.
  4. Last useTIR → TIRFinds the last read of each counted value and hands over its reference there, so an array can change in place without a copy.
  5. MIRTIR → MIRplannedA mid-level form in which every reference-count change is its own statement, so the compiler can remove the pairs that cancel out and check the rest.
  6. CodegenTIR → LLVM IRWrites the program in LLVM's language. Once MIR exists, codegen reads MIR instead.
  7. LLVMLLVM IR → objectOptimizes and writes x86-64 machine code.
  8. Linkobject → executableThe system C compiler, cc, links it with the Sisu runtime.

All stages run in one process, with LLVM linked in as a library. Only the link step calls another program. More on the architecture

Build it and run a program

Sisu has no releases yet. You build the compiler from source, on x86-64 Linux. You need:

  • The Rust toolchain; rustup installs the pinned version
  • GNU Make, and a C compiler on PATH as cc
  • On Ubuntu: libzstd-dev, libxml2-dev, zlib1g-dev
  • prek, which make setup uses to install the Git hooks
