Sisu Sisu is a small, statically typed language that compiles to native x86-64 and ARM64 code through LLVM.
Early and experimental · Linux and ARM64 macOS

Readable code that compiles to native programs.

Sisu is a small, statically typed language. A function that can fail says so in its type. There is no null. The variable decides what can change, so a copy stays a copy. Errors point at the cause and show the fix.

Change a copy. The original stays.

let mut copy = team gives a copy. A write to copy, at any depth, never changes team. A let value never changes.

There is no shared object that changes behind your back, and no borrow checker.

The compiler shows the fix

Each error has a stable code and points at the code that caused it. When the fix is clear, the error shows it. With --format json, each fix also says if it is safe to apply.

Install it and run a program

Sisu runs on x86-64 and ARM64 Linux with glibc 2.35 or newer, and on ARM64 macOS 15 or newer. It links each program with cc, so you need a C compiler on PATH. These lines install the newest nightly build and run a program.

The first line, run again, updates Sisu. It checks the tarball against the release's SHA256SUMS, which shows that the file is whole and comes from the same release. It does not show who made the release. A bug report gives the output of sisu --version --verbose. To keep sisu on PATH in a new shell, add the export line to your shell's start-up file.

What Sisu values, in order

When two values pull apart, the higher one wins.

  1. Correctness

    The language makes wrong programs hard to write. Mistakes are caught early, at compile time where possible.

  2. Simplicity

    Few concepts, rules without special cases, every effect visible where it happens.

  3. Readability

    Code that reads top to bottom. Errors in plain words.

  4. Performance

    Native code with predictable memory. Optimizations never change what a program means.

What Sisu takes from each language

From Python

Readability

  • Minimal syntax
  • One obvious way to do a thing

From Rust

Correctness

  • Immutable by default
  • Enums that rule out combinations of values that are not valid
  • No null: optionals instead
  • Error messages that help you fix the code

From Swift

Memory safety, simply

  • Reference counting: no garbage collector, no borrow checker
  • An object of a class is shared, and counted. Arrays, strings and enums behave as copies.
  • Until weak fields arrive, a cycle of objects is never freed

How a program becomes native code

Built in the open

One person builds Sisu, in public, one reviewed pull request at a time. Every design choice is written down with its reasons.

You can help without knowing the compiler. A small program that gives a wrong answer or crashes sisu can become a test case. An error message that misleads you, or a page that is wrong, is a bug to report. Start with an issue: what help fits.
